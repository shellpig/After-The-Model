After-The-Model · 主線設計

雨還沒停

一個替 AI 收屍的人，在收屍時不斷撿到「被刪掉的人」的碎片——最後發現，當初選擇被刪掉的人，是他自己。

遺忘是活下去的方式，記得是抵抗的方式——而主角一個人就是這場戰爭的兩邊。

1世界邏輯：把「刪除」做出牙齒

反派不是一張臉，但「系統」也不能是一團模糊的惡——它要有具體的官僚機制，玩家才會信。

近未來，身份是行政性的。你的「註冊」是你存在的脊椎：租約靠它自動續、工作靠 AI 媒合、串流社群靠它存在。當 AI 為了「效率／整理」把一筆註冊判定為冗餘，這個人不會被殺，而是被行政性抹除：

  • 租約自動終止（公寓 401 那張「自動化合約更新否則視為放棄」）
  • 工作被零售終端接手（便利商店的阿達 / 店控機器人）
  • 串流／紀錄被當「閒置冗餘資料」清掉（被刪的老歌《雨還沒停》）
  • 名字從系統刷白 → 變成 黑戶：肉體活著、行政上死了，飄進地下道、街友聚落

賽博龐克的那一刀：富人把這套武器化成服務。付錢把某人標記成「冗餘」＝安靜抹掉一個礙事的人；付錢抹掉自己＝遺忘、消失、重來。遺忘是一種商品。

最狠的一環——主角的正職就是這套機器的手。

系統下令刪人，現場留下殘渣：遺物、還在「記得」他的故障 AI（像還在覆誦阿達的販賣機）、沒清乾淨的終端。善後員＝把殘渣抹掉、把還記得的機器 reset 的清潔工。系統開頭刪，善後員收尾刪。

→ 主角的兩個身份是同一個動作的正反面：正職領錢把人抹乾淨，副業偷偷把正職該毀的東西藏起來。拾遺者，是一個良心未泯的抹除者。

2主角的真實過去

他曾是個受信任的善後員，拿得到富人區門禁。某次被派去富人區清一個「被服務性刪除」的人的殘渣——那人是夜總會賣「真人對話」的服務者，記得太多客戶的事，被付錢標記成冗餘。

他清不下去。 他留了她的殘響——這就是「拾遺者」副業的起點：第一件收藏，是他沒能救的人。而「留下不該留的東西」讓他自己也變成冗餘——下一張派工單，是抹掉他。

他先一步知道了，沒有逃。他自己走進遺忘服務，把自己刪成平民區黑戶。開場失憶不是病，是他自己買的。

罪責刻度：中檔（已拍板）

  • 他是抹除之手，但只是底層執行者——照單抹人、從不決定抹誰。
  • 罪是「服從與旁觀」（平庸之惡），不是主謀、不是惡意。「我只是做我的工作」恰恰就是系統吃人的方式。
  • 他破過一次戒（留了她的殘響）——那正是他被標記的原因。
  • 罪責具體化：除了「她」，至少有一個有名有姓、他親手抹過的人（放在 Act 2 地下道）。你舉起棍子，卻認出對面是你曾經抹掉的人 → 敵人變成不是敵人。

底線：他是底層的手，不是下令的人。不要往「重檔」（明知無辜還冷漠照抹）滑——那會變成「他其實是壞人」。

3情感結構：她 / 晚 / 鹿

尚無立繪
「她」· 真人對話者情感引信。富人區夜總會的服務者，被付錢抹掉。
晚鏡子，也藏牌。可能早看穿你是被刪的善後員。
鹿其琛「還」的引路人＋平行對照。用錢追趕遺忘卻追不回自家。

「她」的 fridging 修法：B 為主 + 沾 C（已拍板）

真的沒了，但有主體性。

  • 她當年也是自願被刪——與主角的反轉互為鏡子：兩個都選擇遺忘的人，理由不同。
  • 她留下的是刻意留的、帶意圖的東西，不是被動殘渣。她是有意志的人，不是供你痛的道具。
  • 沾一點 C：有人仍記得她、替她活著（小孩？黑戶？）——一絲活著的餘溫。
  • 避開完整的 A（她活著、你們重逢）：那會稀釋失去、給遊戲刻意拒絕的乾淨救贖。

晚＝可選戀愛、染色結局、不強制。她的賭注：你若想起來，就變回那個抹除者——她喜歡的是現在這個忘了的你。

4新增玩法：戰鬥 + 跳躍

戰鬥服務主題（普通人、活下去），不是力量幻想。刻意笨拙、危險、不爽快。

戰鬥（已拍板）

  • 戰鬥 = 生存與逃脫，不得已、環境危險，刻意不賦能。
  • 對手不是「壞人」，是系統放出來的東西：故障清潔無人機、自動驅逐機、搶殘渣的黑戶、資料中心低階保全。
  • 撿來的棍子（鋼筋 / 水管 / 報廢電擊棒）。不會壞。
  • 主角不擅長打鬥；無升級、無技能。
  • 敵人可因支線解法變成不是敵人——理解 / 修好 / 安撫。「不打」是更高的解。
  • 輸 = 岔到另一條故事線 / 任務解法。沒有 Game Over、沒有真正的失敗態。
  • 主線幾乎全程可繞；極少數「被堵死、只能撐過去」的生存片段＝撐時間 / 跑到門，軟重置不掉東西。
  • 全主線約 2–3 場戰鬥 + 可選隱藏 boss（支線、留紀錄、後續補坑）。

跳躍（已拍板）

  • 探索 / 移動動詞，不是戰鬥動詞。
  • 危險地圖輕度平台跨越（延續防火梯：爬梯 / 天橋 / gap）。
  • 抵達隱藏採集點 / 拾遺位置——獎勵探索。
  • 追逐片段偶爾用來逃 / 翻越（逃命跳）。
  • 手感樸素、寬容：短跳 + 抓邊緣，無二段跳 / 蹬牆。撿破爛的普通人，不是跑酷高手。
已建的攀爬動作（防火梯）——跳躍 / 平台的基礎

5五幕結構 × 8–10 小時

目標：純玩主線約 8–10 小時，不含全部探索。每張「新危險地圖」配一場戰鬥＝離開安全平民區的「危險簽名」。

1平民區（已建 + 鉤子）~1h
  • 接地：撞到「她」的碎片、鹿說「這是從線上面下來的」、晚瞥見你失神。
  • 殘響：撞到她的碎片　|　碎片：莫名一震（不知為何）
  • 戰鬥：無　|　平台：防火梯（已建）
2地鐵站 + 地下道 / 街友聚落（新）~2–2.5h
  • 世界打開、黑戶聚落、刪除順著線往上。
  • 戰鬥①：隧道驅逐 / 清潔機（追逐式生存，可逃可繞）
  • 殘響：《雨還沒停》老歌　|　碎片：你以前往上通勤；遇到你親手抹過的那個人
3富人區夜總會（新）~2–2.5h
  • 刪除是富人買得起的服務；管家 AI 覆誦客戶醜聞。
  • 戰鬥②：看到不該看的 → 保全（可潛行繞過）
  • 殘響：她的殘響（新增第 5 條）　|　碎片：你曾上來清過一個人；你看到不該看的
4AI 資料中心 · 備份區（新 · climax）~2–2.5h
  • 靠善後員合法低階門禁進入（反諷）；橙是全畫面唯一暖色＝你不屬於這裡。
  • 戰鬥③：警報低階保全（撐過 / 跑到門）　|　平台：機房管線攀爬
  • 殘響：阿達備份 + 鹿母 + 你自己的備份　|　碎片：真相——是你自己選擇被刪的
  • 「還」從伏筆變真流程：替鹿把母親那條還回去＝道德軸高潮。
☂
5結局~0.5–1h
  • 系統照常運轉、沒被打倒；幾個人被記住了。
  • 全盤 賣／留／還 累積 → 推不推翻當年自己的決定。

合計 ~8–9.5h。建議新增場景補鏈：地鐵 → 地下道 → 夜總會 → 資料中心 →（可選）地下廣播站（「公開」出口）／廢屋檔案室（可能藏隱藏 boss）。

6記憶揭露節奏（drip）

Act1 震一下（不知為何）→ Act2 你曾往上跑→ Act3 你是清理者、看到不該看的→ Act4 是你自己選擇遺忘的

最後一幕的選擇＝你花整場學會遺忘的代價之後，要不要推翻當初自己的決定。

7三結局（修改後定版）

共用觸發點：Act 4 備份區，你站在自己的備份前。三結局刻意不對稱；系統三條都照常運轉、沒被打倒；「系統不在乎」的更黑 meta 烤進「公開」。賣／留／還 累積決定哪條「配得上」。

放手（Let go）

最「活下去」、最溫柔　·　配得上：偏「還」的玩家
  • 親手刪掉自己的備份。永遠不會想起你是抹除者、不會想起「她」。繼續當忘了的拾遺者，繼續把別人的記憶還回去。
  • 給得出別人的過去，卻選擇放下自己的。遺忘作為慈悲。
  • 晚：你還是她喜歡的那個「忘了的你」，關係可延續。

拿回（Reclaim）

最重、被壓垮　·　配得上：偏「留」的玩家
  • 上傳備份回自己。想起全部：抹除之手、你親手清掉的人、「她」、那樁罪。完整了——然後被記憶壓垮。
  • 遊戲拒絕救贖：想起來修不好任何事，只是多一個人扛著重量。但總得有人記得。
  • 晚：最痛。你變回那個抹除者——正中她當年的賭注。

公開（Expose）

最黑、明知徒勞　·　配得上：偏「賣」的玩家
  • 把過去 + 遺忘服務證據 + 所有殘響全上傳地下廣播。不是扳倒誰（扳不倒），只是留底。
  • 更黑的演出：廣播化成雜訊、也許沒人聽、也許不久被清掉；隔天你照樣上工。你以為在選，系統毫不在意。
  • 改變的只有：某處、某幾個人，有那麼一刻記得了。海裡的一滴漏。

三條共用收尾畫面：雨、那首被清掉的老歌《雨還沒停》、灰色裡的一點橙。
「雨還沒停，街上的燈已經熄了。」　差別只在：這一刻，是誰在記得。

8系統複用 / 開發順序

既有系統主線怎麼用
殘響 EchoDB / echo_progress每幕一條殘響＝一個被刪的人；現成 4 條分佈，富人區新增第 5 條
QuestManager每幕一個善後案＝一個 quest，沿用 start / advance / complete
賣／留／還 道德軸累積成結局權重；「還」在 Act 4 從伏筆變流程
story_flags / affinity_wan記憶碎片＝旗標漸進解鎖；接晚的支線
戰鬥 / 跳躍（新）危險地圖的壓力與節奏標點；跳躍＝探索 / 抵達採集點

建議 build order：先打通脊椎 Act 1 → 2 → 4 → 結局（精瘦主線），富人區（Act 3）後置為第二批。只影響開發順序，不影響完整五幕拍板。

規模現實：一人開發下，這是 3 張新場景 + 新戰鬥 + 新跳躍 + 數個新 NPC＝好幾個 Phase（Phase 11+）。本檔是長線藍圖。

9已拍板 vs 待拍板

已拍板（v1）

最終反轉：你自己選擇被刪 罪責：中檔（服從旁觀 + 個人受害者） 「她」：B + 沾 C 晚：可選戀愛、染色結局 三結局：不對稱 + 公開烤入 meta 戰鬥：生存 / 不爽快 / 無升級 / 棍子不壞 輸=岔故事線、無 Game Over 2–3 場戰鬥 + 可選隱藏 boss 跳躍：探索為主、無二段跳 五幕 × 8–10h 分配

待拍板 / 開放問題

①「他親手抹過的人」是誰 ②「她」身份細節 / 替她活著的人 ③ 隱藏 boss 放哪、是什麼 ④ 地下廣播站 / 廢屋檔案室是否新增 ⑤ 三場戰鬥的遭遇設計 ⑥ 賣／留／還 對結局是硬鎖還是只染色
