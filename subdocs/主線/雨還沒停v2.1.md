## 1. 一句話 / 主題句

- **Logline**：一個替 AI 收屍的人，在收屍時不斷撿到「被刪掉的人」的碎片——最後發現，當初選擇被刪掉的人，是他自己。
- **一句話**：對抗遺忘的拾遺者，自己就是個當年親手替人遺忘、最後也選擇遺忘自己的人。
- **主題句**：不是「記得是否比較勇敢」，而是「**當記得會害死仍活著的人時，你還有沒有權利要求完整的自己**」。
  - 底層情緒仍是：遺忘是活下去的方式，記得是抵抗的方式——而主角一個人就是這場戰爭的兩邊。
- **鐵則**：非英雄、不打倒企業、**系統永遠不會被推翻**。三個結局都不是勝利，差別只在「誰被記住、誰被保住、誰被你連累」。

## 2. 世界邏輯：把「刪除」做出牙齒

近未來，**身份是行政性的**。你的「註冊」是你存在的脊椎：租約靠它自動續、工作靠 AI 媒合、串流社群靠它存在。當 AI 為了「效率／整理」把一筆註冊判定為**冗餘**，這個人不會被殺，而是被**行政性抹除**：

- 租約自動終止（公寓 401 那張「自動化合約更新否則視為放棄」）
- 工作被零售終端接手（便利商店的阿達 / 店控機器人）
- 串流／紀錄被當「閒置冗餘資料」清掉（被刪的老歌《雨還沒停》）
- 名字從系統刷白 → 變成 **黑戶**：肉體活著、行政上死了，飄進地下道、街友聚落

這不是惡意設計，是像清快取一樣清掉多餘的人。

**賽博龐克的那一刀**：富人把這套武器化成服務。付錢把某人標記成「冗餘」＝安靜抹掉一個礙事的人；付錢抹掉自己＝遺忘、消失、重來。**遺忘是一種商品。**

**最狠的一環——主角的正職就是這套機器的手。** 系統下令刪人，現場留下殘渣：遺物、還在「記得」他的故障 AI（像還在覆誦阿達的販賣機）、沒清乾淨的終端。**善後員＝把殘渣抹掉、把還記得的機器 reset 的清潔工。系統開頭刪，善後員收尾刪。**

→ 主角的兩個身份是**同一個動作的正反面**：正職領錢把人抹乾淨，副業偷偷把正職該毀的東西藏起來。**拾遺者，是一個良心未泯的抹除者。**

### 保存也有代價（接 §6 Trace）

黑戶不是只需要被記得；他們也需要**不被系統重新找到**。主角作為拾遺者一直在保存痕跡，但**保存痕跡也可能替系統留下追蹤線**。

→ 拾遺不是天然正義。這條反過來刺中主角的副業，並成為 Trust/Trace 雙軸中 **Trace（系統追蹤風險）** 的世界觀根據（見 §6、§8）。

## 3. 主角的真實過去

他曾是個受信任的善後員，拿得到富人區門禁。某次被派去富人區清一個「被服務性刪除」的人的殘渣——那人是夜總會賣「真人對話」的服務者（真人服務＝奢侈品），記得太多客戶的事，被付錢標記成冗餘。

**他清不下去。** 他留了她的殘響——這就是「拾遺者」副業的起點：他的第一件收藏，是他沒能救的人。而「留下不該留的東西」讓他自己也變成冗餘——下一張派工單，是抹掉他。

他先一步知道了，**沒有逃**。他自己走進遺忘服務，把自己刪成平民區黑戶。

### 自我刪除 = 逃 + 保護

不是只為了逃避痛苦而刪掉自己。他曾看過不該看的東西——**不只是富人的罪，而是那群仍活著黑戶的藏身方式**（見 §4 的「她」）。只要他被抓回系統，他的記憶就會變成追蹤線索。**所以他選擇刪掉自己，既是逃，也是保護。**

→ 開場失憶（已建）不是病，是他自己買的——而且是一個帶倫理重量的行動：他當年也許懦弱，但**不只是**懦弱。

> **把關**：保留**自利的邊**——他保護那個網，有一部分也是因為網一旦被抓，他自己的角色就曝光。別讓「保護別人」把他洗成高尚。罪責維持中檔。

### 罪責刻度：中檔

- 他是**抹除之手，但只是底層執行者**——照單抹人、從不決定抹誰。
- 罪是「**服從與旁觀**」（平庸之惡），不是主謀、不是惡意。
- 他**破過一次戒**（留了她的殘響），那正是他被標記的原因。
- **底線**：他是底層的手、不是下令的人。**不要往「重檔」（明知無辜還冷漠照抹）滑**。

### 罪責回扣縫進阿達：四段式揭露（v2.1 拍板）

把「主角親手抹過的人」縫進 **Phase 8 既有的阿達**（便利商店前店員 / 已成黑戶的前任店員），不發明新 NPC。主角不是阿達悲劇的唯一兇手，但他是行政抹除鏈條的**最後一隻手**。這件事要讓玩家**先懷疑、再否認、最後無法否認**。

**第一段 · 店控機器人誤認（Act 1 後段 / Act 2 開頭）**
玩家回到便利商店，店控機器人短暫故障：
> 「善後員編號確認中……歡迎回來。」
玩家當下只會以為是故障。

**第二段 · 阿達殘響描述「那個人」（Act 2 地下道 / 舊軌道）**
阿達不直接說名字：
> 「他穿雨衣。手上拿著維修棍。
> 他說只是照流程。
> 他說機器記得太多，對我不好。」
玩家開始懷疑，但還能逃避。

**第三段 · 舊善後工單揭露（鎖死 Act 2 後半）**
玩家取得舊善後工單：
- 對象：阿達，便利商店前店員。
- 處理項目：戶籍權限刷白 / 員工權限移除 / 店控機器人記憶重置 / 殘留人聲資料格式化。
- 執行人：主角失憶前的善後員身份。
這一刻正式確認：當年把阿達收尾抹乾淨的人，就是主角。
> **本機把關**：此段**鎖 Act 2 後半，不放 Act 4**。Act 4 已有「你自己的備份」大反轉，兩個「兇手是你」同幕落地會互相鈍化。

**第四段 · 阿達本人短暫登場（僅一次）**
拍板：阿達**可本人短暫登場，但只出現一次、不對話樹、不跟隨、不變主線夥伴**。地點可為地下道深處、黑戶聚落邊緣或資料中心附近。他不是來復仇：
> 「你忘了啊？
> 也好。
> 至少有人可以忘。」
這句是阿達線的情緒收束，守住中檔罪責（不復仇、不洗白）。

## 4. 情感結構：她 / 三張臉 / 晚 / 鹿

### 4.1 「她」——夜總會的真人對話者（行動者）

主線的情感引信。主角這幾個月一直無意識地帶著／追著她的碎片（Act 1 那一震就是撞到她）。拾遺者的收藏從她開始，他卻不記得她是誰。

她不是被抹掉的受害者，而是**用自己的刪除替別人遮蔽**的行動者：

- 她曾替地下道黑戶提供真人對話 / 假履歷 / 情緒資料 / 聲紋片段，幫他們**混過 AI 身份檢查**。
- 她**自願被刪**，不是單純想消失，而是為了讓**那批偽裝資料的來源一起從系統上消失**。
- 她留下的殘響不是「請記得我」，而是「**別把這份名單還給系統**」。
- 她保護的不是一個人，而是**一群黑戶互相偽裝出的生存網 / 一組新身份**——具體即 §4.2 的三張臉。

→ 主角追她，不是追一段愛情或愧疚，而是**被迫接手她未完成的事**。

**她的核心殘響（Act 3 夜總會殘響房間，正式拍板台詞）**：她不是求救、不是告白，留下的是命令——
> 「你要是還在找我是誰，代表你還沒搞懂。
> 重點不是我。
> 重點是別讓他們被找到。」
這段把主線從「尋找她」正式轉成「接手她未完成的事」。

**fridging 修法**：

- 她真的沒了（輓歌與拾遺哀傷成立），但**有主體性**（自願被刪、有意圖、保護別人）。
- 她與主角的反轉**互為鏡子**：兩個都選擇遺忘的人，理由不同。
- **沾一點 C**：她保護的網裡，**有人仍活著、仍記得她**（伍姐記得她、小岑靠她的聲紋活著）——一絲活著的餘溫，不破壞「你救不回」。
- **避開完整的 A**（她活著、你們重逢）：那會稀釋失去、給遊戲刻意拒絕的乾淨救贖。

> **把關**：名單 / 網是**賭注**；鏡頭永遠對著**她這個人**與她保護的**那三張臉**，不要變成「解一份檔案」。

### 4.2 三張臉：黑戶網具體化（v2.1 新增）

「她」保護的不是抽象名單，而是三個玩家會實際見到、互動、甚至不一定喜歡的人。這三人是主線賭注的前景；玩家最後保護的，是這三張仍活著的臉。

**小岑——靠假聲紋活下來的少年黑戶**
- 約 14–16 歲，住地下道邊緣，替聚落跑腿、偷零件、帶路。
- 靠「她」留下的聲紋片段與假履歷，偶爾混過低階 AI 身份檢查。
- 個性不討喜：嘴臭、防備心強、會偷主角東西。不是純潔受害者，是一個已被城市教壞的小孩。
- **功能**：讓玩家看見「她」保護的是未來，但這個未來不乾淨、不感人、也不會感謝你。
- **Protect 結局回收**：主角看見小岑安全通過一次身份檢查；小岑不認得他、甚至嫌他擋路。玩家知道自己保住了他，主角不知道。

**伍姐——前城市維修員，地下道的老維修人**
- 曾是城市基礎設施維修員，後被刷成黑戶；現在管聚落的電力、淨水、舊機器維修。
- 她知道很多「她」的事，但不把她神化。
- **代表台詞**：「她不是好人。她只是比我們晚一點壞掉。」
- **功能**：防止「她」變成聖女。這世界的善意不是純白的，是從交易、恐懼、疲憊裡長出來的。

**七號——想把藏身網賣回系統的人**
- 沒固定名字，大家叫他「七號」。曾被「她」救過，現在想把藏身網的一部分交給系統，換回合法身份。
- 不是反派，是另一種求生者：他相信聚落遲早被清掉，不如先賣掉一部分人換一條活路。
- **功能**：讓黑戶群體不是單純受害者——被壓迫的人也會背叛、算計、出賣別人。
- **Act 3 / Act 4 連動（即 §7 的小爆點引擎）**：七號是系統重新找到黑戶網的破口之一。玩家長期「留」太多未清洗殘響 → Trace 上升 → 七號更容易拼出藏身網；玩家「還」得夠多 / Trust 夠 → 伍姐或小岑提前警告主角。

### 4.3 晚——鏡子，不是獎品（v2.1 加私心）

- 她其實比她說的更知道你是誰：可能早看穿你是個被刪的善後員。「等你值得了再一個字一個字給你」不是調情，是保護與試探。
- **她反對的不是你想知道真相**，而是**你把活人的安全拿去換自己的完整**——但這不是她的全部理由。
- **Act 4 拉扯台詞（拍板）**：
  - 原方向（活人安全）：
    > 「你可以想起來。但你要先知道，你想起來以後，**誰會被你一起拖回系統裡**。」
  - **新增私心版本**：
    > 「我說是為了他們。
    > 可是也有一點，是為了我自己。
    > 你想起來以後，就不會是現在這個你了。」
- → 晚不是道德指南，而是一個也會害怕、也會自私、也想留下某個版本主角的人。
- **戀愛=可選支線**：不強制，但她的賭注染色結局（見 §8）。

### 4.4 鹿其琛——「還」的引路人＋平行對照

- 「還」的引路人：他母親的殘響（`echo_lu_family`，他不收不談）是錢買不回的記憶；主角能替他做他腿腳做不到的事。
- 主題的鏡子：一個用錢追趕遺忘、卻追不回自家的人。他不深度捲進主角祕密。
- **Trust/Trace 連動**：在「還」帶風險的新框架下（§6），替鹿把母親那條還回去，也要面對「會不會把某個原主重新納回系統」的微決定；可先「清洗」再還以壓低 Trace。

## 5. 新增玩法系統：戰鬥 + 跳躍

> 戰鬥**服務主題（普通人、活下去）**，不是力量幻想。刻意笨拙、危險、不爽快。

### 5.1 戰鬥定位

- 戰鬥 = **生存與逃脫**，不得已、環境危險，刻意不賦能。
- 對手不是「壞人」，是**系統放出來的東西**：故障 / 野化清潔無人機、自動驅逐 / 執法機、搶殘渣的黑戶、資料中心低階保全。
- **撿來的棍子**（鋼筋 / 水管 / 報廢電擊棒），**不會壞**。主角**不擅長打鬥**；**無升級、無技能**。
- 高潮永遠是記憶揭露，不是打贏誰。

### 5.2 維修式「格式化重置」戰鬥（限機器敵人）

把戰鬥綁回善後員本職（維修 / 清理工），讓「理解 / 修好，而不是打爆」變成字面上的核心動詞：

- **棍子弱傷害**：敲擊故障無人機 / 執法機，主要效果是**短暫癱瘓（Stun）/ 打斷動作**，而非直接消滅。
- **核心解法 = 格式化**：用**輕跳 + 走位繞到機器人後方 / 上方**，按住主互動鍵（E）進行**「強制格式化重置（Reset）」**。
- 玩法質感：藍領工人的維修與除錯，與善後員設定在操作上合一。

**邊界**：

- 「格式化重置」**只對機器人 / 無人機**成立。**對人類敵人**（搶殘渣的黑戶、保全）不能格式化 → 走**嚇退 / 撐過 / 對話 / 交易 / 環境阻隔 / 逃**。主角可揮棍自保，但不進入「打贏人」的玩法邏輯。
- **reset（戰鬥解）≠ defuse（非戰鬥解）**：支線預先「理解 / 修好 / 安撫」可讓某些敵人**根本不出現或變成不是敵人**（也呼應 §3「認出曾抹過的人」）；reset 是你沒解開時、當場制伏機器的退路。

### 5.3 失敗模型

- **沒有真正的「失敗態」、沒有 Game Over。**
- **打輸 = 岔到另一條故事線 / 任務解法。** 贏和輸都是有效路徑。
- 強制生存片段沒撐過 = 該段**軟重置**（回片段開頭），不掉東西。

### 5.4 戰鬥先做 Act 2 一場原型（v2.1 scoping 拍板）

戰鬥不全面展開。第一階段只製作一場完整原型，確認可玩後再擴張。

**Act 2 戰鬥原型：隧道清潔機**
- 地點：廢棄地鐵隧道。敵人：故障清潔／驅逐機。
- 核心流程：①敵人巡邏 → ②發現後追擊 → ③玩家可逃跑 / 躲避 / 繞路 → ④棍子攻擊只造成短暫 stun → ⑤跳上平台或繞到背後 → ⑥按住 E「強制格式化重置」→ ⑦成功後敵人進入低功率待機 → ⑧失敗不 Game Over，被迫掉入另一條路線。
- 戰鬥感受：笨拙、危險、勉強撐過，像藍領維修工處理失控機器。玩家不是英雄，只是剛好知道怎麼讓壞掉的東西安靜。

### 5.5 戰鬥場景數量（長線目標）

- 全主線約 **2–3 個戰鬥場景**（不含主題型遭遇 P-00），各對應一張「新危險地圖」。
- 第一版只落地 Act 2 原型；Act 3 / Act 4 戰鬥隨場景開工再做。

### 5.6 跳躍

- **jump = 探索 / 移動動詞，不是戰鬥動詞**（但在 §5.2 用於繞後）。
- 危險地圖輕度平台跨越（延續防火梯）；抵達隱藏採集點 / 替代路線；追逐片段逃 / 翻越。
- 手感樸素、寬容：短跳 + 抓邊緣，**無二段跳 / 蹬牆**。

## 6. `賣／留／還` → Trust / Trace 雙軸（v2.1 拍板）

`賣／留／還` 不再只是道德分數，背後改成兩個**隱性狀態**。玩家不會直接看到數值，但會從 NPC 反應、任務路線、結局染色感受到：

- **Trust（他人信任）**
- **Trace（系統追蹤風險）**

| 選擇 | 行為 | Trust | Trace | 世界觀意義 | 染色傾向 |
|---|---|---|---|---|---|
| **賣** | 把殘響賣掉換資源 / 錢 / 情報 / 通行 | 下降 | 下降（手上少一份可被追蹤的原始資料） | 你把別人的存在再次商品化 | Edited Expose（諷刺：賣記憶的人最後把整個市場連自己一起攤開） |
| **留** | 把殘響保存在自己手上 | （晚對你產生矛盾態度：理解你想記得，但不信任你能承擔後果） | 上升（保存原始痕跡留下追蹤線） | 情感保存最多、解鎖更多回憶 / 旁支 / 城市碎片 | Reclaim（什麼都不肯放手的人，最後連最痛的自己也要拿回來） |
| **還** | 把殘響交還當事人 / 家屬 / 該有處置權的人 | 上升（某些 NPC 主動幫助主角） | 若未清洗敏感資料仍可能上升 | 把記憶的處置權還給別人，不是單純善良 | Protect（把別人的過去還給別人，最後也把自己的完整讓出去） |

### 6.1 清洗：讓「還」不是固定正解

玩家在某些情況下可多花時間清洗殘響：刪定位資訊 / 模糊聲紋 / 移除原始系統標記 / 只留情感內容而非可追蹤資料。

- 清洗後再「還」：Trust 上升、Trace 較低。
- **代價**：清洗會損失部分真相，**玩家永遠無法知道自己刪掉了多少細節**。

### 6.2 落地順序（build order，已拍板）

第一版只實作 **Trace 單軸 + 清洗**（追蹤風險是主線賭注的核心齒輪，程式無現成等價物，必須新建），**Trust 暫用既有 `affinity` 系統近似**；待原型站穩、需要「社群層級信任 vs 逐個 NPC 好感」的細膩度時，再把 Trust 獨立成專軸。此為 build order 拍板，不改 §6 的雙軸設計。

## 7. 五幕結構 × 8–10 小時分配（含七號小爆點）

> 目標：純玩主線約 **8–10 小時**，不含全部探索。每張「新危險地圖」配一場戰鬥＝離開安全平民區的「危險簽名」。

| 幕 | 場景 | 主線時長 | 戰鬥 | 跳躍 / 平台 | 敘事重心 | 殘響 | 自我碎片（旗標漸解） |
|---|---|---|---|---|---|---|---|
| **1** | 平民區（**已建** + 鉤子） | ~1h | 無 | 防火梯（已建） | 接地、撞到「她」的碎片、鹿說「這是從線上面下來的」、晚瞥見你失神；**阿達四段①店控誤認** | 撞到她的碎片 | 莫名一震（不知為何） |
| **2** | 地鐵站 + 地下道 / 街友聚落（新） | ~2–2.5h | **戰鬥①** 隧道清潔機原型（格式化重置或逃，可繞） | 軌道 / 月台跨越 | 世界打開、黑戶聚落、**認識小岑 / 伍姐 / 七號**；刪除順著線往上；**阿達四段②殘響＋③工單（Act 2 後半確認你是加害者）** | 《雨還沒停》老歌（城市記憶母題，非主角身世鑰匙） | 你以前往上通勤；黑戶半認得你；**你親手抹過阿達** |
| **3** | 富人區夜總會（新；第一版至少 15–20min 殘響房間核心片段） | ~2–2.5h | **戰鬥②** 看到不該看的 → 保全（人類敵人：潛行繞過 / 撐過） | 屋頂 / 管線 | 刪除是富人買得起的服務；管家 AI 覆誦客戶醜聞；**她的核心殘響「別讓他們被找到」** | 她的殘響 = 「別把名單還給系統」 | 你曾上來清過一個人；你看到的是**那群黑戶的藏身方式** |
| **3→4 過場** | **小爆點：七號背叛**（point of no return） | ~0.3–0.5h | 視解法（攔阻 / 逃 / 撐過；可含機器或環境，不一定新增正式戰鬥） | 追逐 / 翻越 | **七號要把藏身網的一部分賣回系統換合法身份** → 三張臉即將曝光，主角被迫行動 | （連動既有殘響，無新增） | 你不再只是旁觀者；你正在做「她」做過的事 |
| **4** | AI 資料中心 · 備份區（新，**climax**） | ~2–2.5h | **戰鬥③** 警報低階保全（撐過 / 跑到門） | 機房管線攀爬 | 靠善後員合法低階門禁進入（反諷）；橙是全畫面唯一暖色＝你不屬於這裡；**晚在此拉扯**（§4.3，含私心台詞）；**阿達四段④本人登場一次（可選地點）** | 阿達備份 + 鹿母 + **你自己的備份** | **真相：你自己選擇被刪，是為了保護那個網** |
| **5** | 結局 | ~0.5–1h | 無 | 無 | 系統照常運轉，沒被打倒 | 全盤 Trust/Trace 累積 | 拿回自己 / 保住別人 / 刪改公開（§8） |

**合計 ~8.3–9.5h。**

### 七號小爆點細節（Act 3→4 過場）

- **引爆物**：七號試圖把藏身網的一部分交給系統，換回自己的合法身份——不是惡意，是另一種求生。
- **觸發染色（接 §6 Trace）**：
  - 玩家長期「留」太多未清洗殘響 → Trace 高 → 七號更容易拼出整張網 → 爆點更危急、可挽回空間更小。
  - 玩家「還」得夠多 / Trust 夠 → 伍姐或小岑**提前警告**主角 → 玩家有機會先一步介入。
- **玩法**：沿用既有系統——對話 / 威嚇 / 交易（人類衝突，不格式化）+ 追逐 / 翻越（§5.6 跳躍）。**不一定要新增一場正式戰鬥**。
- **成敗皆有效路徑（§5.3）**：攔下七號 / 沒攔下，都通往 Act 4，只是改變誰已曝光、Act 4 與結局的染色。
- **位置理由**：填補 Act 3 收在「揭露台詞」缺動能標點的凹陷；是進 climax 前的 point of no return；外部動作爆點與 Act 4 內向安靜反轉成反差，不互相稀釋；正中 v2.1 主題「保存 / 知道也有代價」。

### 設計重點

- 「**還**」在 Act 4 從伏筆變真流程，且**帶 Trace 風險**：替鹿把母親那條還回去＝道德軸高潮，但也要面對「會不會把原主重新納回系統追蹤」（可先清洗）。
- 建議新增場景補鏈：地鐵 → 地下道 / 街友聚落 → 富人區夜總會 → AI 資料中心 →（可選）地下廣播站（「公開」結局出口）／ 廢屋檔案室（可能藏 P-00 主題型遭遇）。

## 8. 三結局（Codex 軸 + v1 人味 + Gemini 後果 + v2.1 加痛）

三條共用觸發點：**Act 4 備份區，你站在自己的備份前**——那個「被刪之前的你」。你已經知道：不是別人刪了你，是你自己選的，而且是為了保護那個網。

**軸**：你最後不是選真相或謊言，而是**選誰有權擁有哪一部分真相**。
**前景**：每條結局的情感落點掛在**具體的人**（她、三張臉、鹿母、阿達、晚），不是抽象名單。
**後果**：Trust/Trace 累積決定哪條「配得上」並染色呈現；**傾向只染色 + 少量軟門檻，不硬鎖**（見 §12 待拍板）。
三版共用收尾畫面：雨、那首老歌《雨還沒停》、灰裡的一點橙。

### 拿回自己（Reclaim）——最重、最自私

你把備份上傳回自己，想起**全部**：抹除之手、你親手清掉的阿達、「她」、那樁罪。你完整了——然後被記憶壓垮。**但你也重新帶回一組會害死黑戶的可追蹤真相。** 完整自己，是拿別人的安全去換的。

- **遊戲拒絕救贖**：想起來修不好任何事，只是多一個人扛著重量、且多一份危險。
- **晚**：最痛。你變回那個抹除者——正中她的賭注。回到公寓後晚徹底失望、消失，後續地圖不再出現。
- **配得上**：偏「**留**」、Trust 低 / Trace 高的玩家——什麼都不肯放手的人，最後連最痛的自己也要拿回來，哪怕代價是別人。

### 保住別人（Protect）——最「活下去」、主動的犧牲（v2.1 加痛，不是 Good Ending）

你親手刪掉自己的備份。你**刻意**繼續當忘了的拾遺者——不是被動解脫，而是**為了保護那個網**主動放棄。你連「知道自己為何這麼做」的權利都放棄了。它保留溫度，但加回不可修復的痛：

- **小岑回收**：結尾你看見小岑安全通過一次低階身份檢查、沒被系統抓回。但他不認得你、甚至嫌你擋路——
  > 「大叔，站那邊幹嘛？雨很大欸。」
  玩家知道這代表主角成功了；主角不知道。
- **晚的餘溫保留，但不能太甜**：她仍可出現在公寓窗邊看雨，但這不是戀愛獎勵、不是圓滿。她知道你做了什麼——
  > 「你又變回來了。」
  > 主角問：「變回什麼？」
  > 晚看著雨，沒有回答。
- **阿達無法被修復**：即使保住黑戶網，阿達那件事仍然發生過。阿達不會原諒他；或更狠——阿達根本不在乎原不原諒，因為被抹掉的人沒有義務完成主角的救贖。
- **演出把關**：要讓玩家清楚感覺「這次遺忘是**選擇**、是**為了誰**」，不能跟單純放手混淆。
- **配得上**：偏「**還**」、Trust 高的玩家——把記憶（的處置權）還給別人的人，最後也把自己讓了出去。

### 刪改後公開（Edited Expose）——最黑、握著刀

你把過去 + 遺忘服務的證據 + 殘響上傳地下廣播。不是扳倒誰（扳不倒），只是**留底**。但**公開 ≠ 全公開**：你必須決定**是否刪去能指向活人的部分**。

- **更黑的演出**：廣播化成雜訊、也許沒人聽、也許不久被當冗餘清掉；隔天你照樣上工；系統根本不在乎。**你以為在選，系統毫不在意。**
- **軟門檻**：必須在遊戲中「**還**」了足夠殘響（Trust / 清洗到位），才能解開加密並發送；**還得太少 → 公開被系統靜默攔截、完全無效**，呈現極致虛無。
- 改變的只有：某處、某幾個人，有那麼一刻記得了。**海裡的一滴漏。**
- **配得上**：偏「**賣**」的玩家別有諷刺——把記憶當商品賣掉的人，最後把整個市場、連自己一起，（刪改後）攤開給所有人看。

> 三條共用收尾：「雨還沒停，街上的燈已經熄了。」差別只在：**這一刻，是誰在記得、誰被保住、誰被你連累。**

## 9. 隱藏內容：P-00 主題型遭遇（v2.1 拍板，暫緩、非力量挑戰）

隱藏 boss 不在第一階段拍板成正式戰鬥。若保留，定位改為**主題型遭遇**。

**總清機 P-00**：一台舊型善後機器，曾協助處理大量被刪除者的殘留資料。它沒有強烈敵意，只是壞掉後不斷重複過去的清理流程。它像主角的機械鏡像——都是善後工具、都曾把人抹乾淨、都殘留了不該留下的記憶、都不知道自己算不算有罪。

**遭遇方式**（不是單純打贏，而是選擇如何處理它）：

1. **Reset 它**：讓它安靜，停止痛苦，也停止記得。
2. **留著它**：保存它體內所有被格式化過的殘響，但 Trace 大幅上升。
3. **還 / 公開它的資料**：把部分紀錄交給地下廣播或相關家屬，但可能暴露仍活著的人。

**落地**：不必放進第一版主線；適合作為後期支線、隱藏區域，或資料中心旁支內容（候選位置：廢屋檔案室）。

## 11. 開發順序與規模

- **建議 build order**：先打通脊椎 **Act 1 → 2 → 4 → 結局**（精瘦主線）；**Act 3 至少保留 15–20min 夜總會核心片段**（不可完全跳過），完整富人區後置為第二批。戰鬥先做 **Act 2 隧道清潔機原型**；Trust/Trace 先做 **Trace 單軸 + 清洗**。只影響開發順序，不影響完整五幕拍板。
- **規模現實（已接受）**：v2.1 把主題落到三張臉、四段阿達、Trust/Trace、夜總會片段、七號爆點、P-00——**要做完整個主線，規模勢必擴大**。一人開發下這是 3 張新場景 + 新戰鬥 + 新跳躍 + 雙軸狀態 + 數個新 NPC＝好幾個 Phase（Phase 11+）。本檔是排序好的長線藍圖，落地時須拆 Phase，並把上述「先行項」當第一批 MVP。

## 12. 已拍板 vs 待拍板

### 已拍板（v2.1）

- 最終反轉：**你自己選擇被刪**（既是逃也是保護）。
