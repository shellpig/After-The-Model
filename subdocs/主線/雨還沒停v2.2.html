1世界邏輯：把「刪除」做出牙齒

反派不是一張臉，但「系統」也不能是一團模糊的惡——它要有具體的官僚機制，玩家才會信。

近未來，身份是行政性的。你的「註冊」是你存在的脊椎：租約靠它自動續、工作靠 AI 媒合、串流社群靠它存在。當 AI 為了「效率／整理」把一筆註冊判定為冗餘，這個人不會被殺，而是被行政性抹除：

  • 租約自動終止（公寓 401 那張「自動化合約更新否則視為放棄」）
  • 工作被零售終端接手（便利商店的阿達 / 店控機器人）
  • 串流／紀錄被當「閒置冗餘資料」清掉（被刪的老歌《雨還沒停》）
  • 名字從系統刷白 → 變成 黑戶：肉體活著、行政上死了；且失去一切家屬資格（七號因此無權查妹妹）

賽博龐克的那一刀：富人把這套武器化成服務。付錢把某人標記成「冗餘」＝安靜抹掉一個礙事的人；付錢抹掉自己＝遺忘、消失、重來。遺忘是一種商品。

最狠的一環——主角的正職就是這套機器的手。

系統下令刪人，現場留下殘渣：遺物、還在「記得」他的故障 AI、沒清乾淨的終端。善後員＝把殘渣抹掉、把還記得的機器 reset 的清潔工。系統開頭刪，善後員收尾刪。

→ 兩個身份是同一個動作的正反面：正職領錢把人抹乾淨，副業偷偷把正職該毀的東西藏起來。拾遺者，是一個良心未泯的抹除者。而保存痕跡也可能替系統留下追蹤線——這是 Trace 的世界觀根據。

2主角的真實過去 · 阿達四段式

他曾是受信任的善後員。某次被派去富人區清一個「被服務性刪除」的人——夜總會賣「真人對話」的服務者，記得太多客戶的事，被付錢標記成冗餘。

他清不下去。 他留了她的殘響——拾遺者副業的起點，第一件收藏是他沒能救的人。「留下不該留的東西」讓他也變成冗餘，下一張派工單是抹掉他。

他先知道了，沒有逃。他自己走進遺忘服務，把自己刪成黑戶。自我刪除＝逃 + 保護：他看過那群黑戶的藏身方式，只要被抓回系統，他的記憶就變追蹤線。

罪責刻度：中檔（已拍板）

  • 他是抹除之手，但只是底層執行者——照單抹人、從不決定抹誰。罪是「服從與旁觀」（平庸之惡）。
  • 他破過一次戒（留了她的殘響）——那正是他被標記的原因。
  • 保留自利的邊：他保護網，一部分也因為網一旦被抓、他自己的角色就曝光。別洗成高尚。
  • 底線：底層的手、不是下令的人。不要往「重檔」滑。

罪責回扣縫進阿達：四段式揭露（讓玩家先懷疑、再否認、最後無法否認）

段落點內容
①Act 1 後段 / 2A店控機器人誤認：「善後員編號確認中……歡迎回來。」當下只像故障。
②Act 2C阿達殘響：「他穿雨衣。手上拿著維修棍。他說只是照流程。」開始懷疑、還能逃避。
③鎖 Act 2C舊善後工單：對象＝阿達、處理＝戶籍刷白 / 店控記憶重置 / 人聲格式化、執行人＝失憶前的你。正式確認兇手是主角。
④後期（僅一次）阿達本人短暫登場、不跟隨、不復仇：「你忘了啊？也好。至少有人可以忘。」

把③鎖死 Act 2C、不放 Act 4——避免和「你自己的備份」兩個「兇手是你」同幕互鈍化。

3情感結構：她 / 三張臉 / 晚 / 鹿

「她」保護的不是抽象名單，而是三個玩家會實際見到、互動、甚至不一定喜歡的人。玩家最後保護的，是這三張仍活著的臉。

「她」尚無立繪
小岑 · 少年黑戶14–16 歲，靠她的假聲紋混過身份檢查。嘴臭、會偷東西、不會感謝你。
尚無立繪
伍姐 · 老維修人前城市維修員。「她不是好人。她只是比我們晚一點壞掉。」
尚無立繪
七號 · 想賣網的人有個妹妹仍在系統內。願意拿別人換確認她還活著的權利。

「她」——夜總會真人對話者，從裝置 → 行動者。

她自願被刪，不是想消失，而是讓那批偽裝資料的來源一起從系統消失。殘響不是「請記得我」，而是命令——

「你要是還在找我是誰，代表你還沒搞懂。重點不是我。重點是別讓他們被找到。」

fridging 修法：真的沒了（輓歌成立）、但有主體性；與主角互為鏡子；沾一點 C（伍姐記得她、小岑靠她活著）；避開完整的 A（不重逢、不乾淨救贖）。

晚 — 鏡子，不是獎品（含私心） 她反對的不是你想知道真相，而是你拿活人安全換自己的完整。Act 4 私心版台詞：「我說是為了他們。可是也有一點，是為了我自己。你想起來以後，就不會是現在這個你了。」
鹿其琛 — 「還」的引路人 用錢追趕遺忘卻追不回自家。替他把母親那條殘響還回去＝道德軸高潮，但也要面對「會不會把原主重新納回系統」。

「還」母題鏈 — 預示 Protect 結局

鹿的母親替鹿還回他腿腳到不了的記憶
七號的妹妹給他「那個人還在」的證明
主角自己前兩個你都還得出去，唯獨自己的完整還不回

4七號妹妹線 · 回執 · 和平線

七號的核心：他不是想回系統享福，而是想確認妹妹是否還活著。這讓他的背叛成為主題句的變奏——當找回某個人會害死仍活著的人時，你怎麼選。他要賣掉網去找回妹妹，主角當年刪掉自己去保護網。兩人是同一道不可能選擇的正反解。

關鍵道具：兒少照護補給回執

取得：Act 2B 隧道清潔機戰鬥後的探索區（照護補給箱 / 舊行政物流）。

表面：像一張沒價值的物流單——配送紀錄、模糊化收件代碼、營養包 / 學習終端耗材、最近配送成功、沒有完整姓名。可當雜物賣給晚。

真正用途：七號能認出代碼、舊暱稱、手寫符號或錯字。它證明——妹妹仍在系統內、近期仍在收照護補給、沒被刷白 / 死亡登記。它不保證她幸福，只證明她還在、暫時安全。對七號來說已經足夠。

賣給晚（一次「賣」）

晚輕提醒、不解謎、不阻止：

「這種回執沒什麼價。除非你知道上面的代碼是誰的。」

仍賣掉 → Trust / Trace 皆降，鎖死和平線。呼應清洗「你永遠不知道自己丟掉了什麼」。

給回執（一次「還」）

把證明「某個人還在」交還該擁有它的人：

Trust ↑　·　Trace 不升或微降

與「替鹿還母親殘響」並列為「還」的兩個具體特例。

七號和平成功線 — 稀有恩典（不加路標）

漏斗很窄、第一輪多數玩家會錯過——這是刻意的
  • 觸發：持有回執 + 事件爆發前主動找七號 + 不威脅 / 嘲諷 / 逼問 + 選擇交還。
  • 對話：七號先不信 →「那你就不知道你拿著什麼。」→「所以我拿來問你。」→ 認出代碼後沉默崩裂：「她還在。」「那我不能回去。」「我一回去，他們就會順著我找到她。」「……幹。」
  • 結果：他自願放棄交網。不是溫馨和解——不立刻成朋友、仍不全信你、可能離開聚落一段時間。留下：「我欠你一次。不是欠你們。是欠你。」

把關：七號同情化 = 世界軟一格，但醜陋搬進他本人

接受「沒有卡通壞蛋」，但這不是變善良——而是把醜陋從「角色人設」搬進「系統壓力下普通人會做的事」：一個愛妹妹的哥哥，準備把一個小孩（小岑）和伍姐的身份賣回系統。這比扁平叛徒更黑、更難脫鉤。四條守則：

  • 背叛要具體、不准美化：明寫他要賣的是小岑的位置、伍姐的舊身份。
  • 同情不能買掉後果：攔下 / 部分流出分支，七號不被回溯赦免；小岑的暴露照樣是真的。
  • 三張臉各守本職：伍姐繼續反神化、小岑繼續不討喜，別讓他們扛背叛質地。
  • （可選）留一撮無救贖的灰：一個質地鏡頭即可，讓聚落不會整個變成一個擁抱。

另一個方向的風險：對本作氣質更大的威脅是妹妹揭露本身的煽情。守住「不保證幸福、只證明還在」的冷度，比找替補惡人重要得多。

5Trust / Trace 雙軸 + 清洗

賣／留／還 不再只是道德分數，背後是兩條隱性狀態（玩家不直接看到數值，從 NPC 反應、任務路線、結局染色感受）。Trust＝對人、Trace＝對系統，是兩條獨立的軸。

選擇TrustTrace世界觀意義染色傾向
賣↓↓（原始資料離手）把別人的存在再次商品化Edited Expose（諷刺）
留矛盾 / 偏↓↑（保存即留線）情感保存最多、解鎖最多回憶Reclaim
還↑未清洗仍可能↑把記憶的處置權還給別人Protect

清洗：刪定位 / 模糊聲紋 / 移除系統標記 / 只留情感內容。清洗後再還 → Trust↑、Trace 較低。

代價：損失部分真相，你永遠無法知道自己刪掉了多少細節。

落地順序（已拍板）：第一版「Trace 單軸 + 清洗」先行（核心齒輪、無現成等價物）。

Trust 暫用既有 affinity 近似，等需要「社群層級信任 vs 逐個 NPC 好感」的細膩度再獨立。

6戰鬥 + 跳躍

戰鬥服務主題（普通人、活下去），不是力量幻想。刻意笨拙、危險、不爽快。

維修式「格式化重置」（限機器）

  • 對手是系統放出來的東西：故障清潔 / 驅逐機、保全。撿來的棍子不會壞、無升級無技能。
  • 棍子只造成短暫 stun；核心解＝輕跳繞後 + 按住 E 強制格式化重置。藍領維修工的操作，與善後員本職合一。
  • 人類敵人不格式化：走嚇退 / 交易 / 環境阻隔 / 逃。
  • 輸 = 岔到另一條故事線，無 Game Over。
  • 先做 Act 2B 一場原型（隧道清潔機），可玩再擴張；長線約 2–3 場。

跳躍

  • 探索 / 移動動詞（戰鬥僅用於繞後）。
  • 危險地圖輕度平台跨越（延續防火梯）；抵達隱藏採集點；追逐逃 / 翻越。
  • 手感樸素、寬容：短跳 + 抓邊緣，無二段跳 / 蹬牆。
已建的攀爬動作（防火梯）——跳躍 / 平台的基礎

7五幕結構（Act 2 拆段）· 七號三分支

純玩主線約 8–10 小時。記憶揭露節奏：

Act1 震一下（不知為何）→ Act2C 你親手抹過阿達→ Act3 你看到的是藏身方式→ Act3→4 七號背叛→ Act4 是你自己選擇被刪的
1平民區（已建 + 鉤子）~1h
  • 撞到「她」的碎片、鹿說「從線上面下來的」、晚瞥見你失神。碎片：莫名一震
  • 阿達①店控誤認　|　戰鬥：無
2地鐵站 + 地下道 / 街友聚落（新 · 拆 2A–2D）~2–2.5h
2A 認識三張臉

打開世界、被刪的人仍活著；七號提「我有一個名字還掛在上面」（不明說妹妹）。

2B 戰鬥原型 + 取得回執

隧道清潔機（格式化重置）；戰後探索撿到回執（此時只是雜物）。

2C 阿達罪責揭露

阿達殘響 + 舊工單，確認兇手是你。獨立給足情緒重量，不與七號線重疊。

2D 七號可選對話

賣回執給晚，或帶回執找七號（觸發稀有恩典和平線）。是 Act 3→4 爆點的提前埋雷。

3富人區夜總會（新 · 至少 15–20min 殘響房間）~2–2.5h
  • 刪除是富人買得起的服務；管家 AI 覆誦客戶醜聞。
  • 戰鬥②：看到不該看的 → 保全（人類：潛行 / 撐過）
  • 殘響：她的核心殘響「別讓他們被找到」　|　碎片：你看到的是黑戶藏身方式
★小爆點：七號背叛（Act 3→4 過場 · point of no return）~0.3–0.5h

七號要把藏身網一部分賣回系統換確認妹妹的資格 → 三張臉即將曝光。Trace 連動：留太多 → 他更容易拼出網；還得夠 / Trust 夠 → 伍姐或小岑提前警告你。玩法沿用對話 / 威嚇 / 交易 + 追逐 / 翻越，不一定新增正式戰鬥。

4AI 資料中心 · 備份區（新 · climax）~2–2.5h
  • 靠善後員合法低階門禁進入（反諷）；橙是全畫面唯一暖色＝你不屬於這裡。
  • 戰鬥③：警報低階保全（撐過 / 跑到門）　|　平台：機房管線攀爬
  • 晚拉扯（含私心）；阿達④本人登場一次。
  • 殘響：阿達備份 + 鹿母 + 你自己的備份　|　真相：是你自己選擇被刪的，為了保護那個網
☂
5結局~0.5–1h
  • 系統照常運轉、沒被打倒；幾個人被記住了。
  • 全盤 Trust / Trace 累積 → 拿回自己 / 保住別人 / 刪改公開。

七號事件三分支（不採用「完全沒攔下大災難」線）

D · 和平成功

用回執讓七號自願放棄（稀有恩典）
  • 藏身網沒流出；七號不成朋友但不再主動背叛；聚落壓力最低；Act 4 壓力較低，但系統仍可能因其他 Trace 線索逼近。

A · 成功攔下

沒觸發和平線，但事件爆發後攔下他
  • 網沒完整流出；七號怨恨你；聚落暫安全但裂痕加深；Trust 不一定上升（你只阻止災難、沒理解他）；Act 4 正常推進。

B · 部分攔下

沒完全阻止，或 Trace 過高致他已拼出部分
  • 系統取得一部分線索；小岑或伍姐其一暴露風險上升；Act 4 可見檔案被重新標記；結局更黑；仍不導致大型 NPC 死亡或主線斷裂。

不做大災難線：避免一次失敗過大懲罰、避免喧賓奪主蓋過 Act 4 自我反轉、避免主線變拯救聚落英雄劇。失敗改變染色與代價，但不推進懲罰性壞線。

8三結局

共用觸發點：Act 4 備份區，你站在自己的備份前。軸＝你選誰有權擁有哪一部分真相；前景＝掛在具體的人；後果＝Trust / Trace 染色，傾向只染色 + 少量軟門檻、不硬鎖。

拿回自己（Reclaim）

最重、最自私　·　配得上：偏「留」、Trust 低 / Trace 高
  • 上傳備份回自己，想起全部——然後被記憶壓垮。但你也帶回一組會害死黑戶的可追蹤真相。
  • 遊戲拒絕救贖：想起來修不好任何事，只是多一個人扛重量、且多一份危險。
  • 晚：最痛。你變回那個抹除者——正中她的賭注，回公寓後她徹底失望、消失。

保住別人（Protect）— 加痛，不是 Good Ending

最「活下去」、主動的犧牲　·　配得上：偏「還」、Trust 高
  • 親手刪掉自己的備份，刻意繼續當忘了的拾遺者，為保護那個網主動放棄。
  • 小岑回收：你看見他安全通過身份檢查，他卻不認得你——「大叔，站那邊幹嘛？雨很大欸。」你知道你成功了；主角不知道。
  • 晚不能太甜：「你又變回來了。」「變回什麼？」晚看著雨，沒有回答。
  • 阿達無法被修復；七號（若走過和平線）留下＝又一張臉保住。呼應還母題鏈。

刪改後公開（Edited Expose）

最黑、握著刀　·　配得上：偏「賣」的玩家別有諷刺
  • 把過去 + 遺忘服務證據 + 殘響上傳地下廣播。公開 ≠ 全公開：你必須決定是否刪去能指向活人的部分。
  • 軟門檻：必須「還」了足夠殘響才能解開加密發送；還得太少 → 被系統靜默攔截、完全無效。
  • 更黑的演出：廣播化成雜訊、也許沒人聽；隔天你照樣上工。你以為在選，系統毫不在意。

三條共用收尾：雨、那首被清掉的老歌《雨還沒停》、灰色裡的一點橙。
「雨還沒停，街上的燈已經熄了。」　差別只在：這一刻，是誰在記得、誰被保住、誰被你連累。
