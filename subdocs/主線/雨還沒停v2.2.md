## 1. 一句話 / 主題句

- **Logline**：一個替 AI 收屍的人，在收屍時不斷撿到「被刪掉的人」的碎片——最後發現，當初選擇被刪掉的人，是他自己。
- **一句話**：對抗遺忘的拾遺者，自己就是個當年親手替人遺忘、最後也選擇遺忘自己的人。
- **主題句**：不是「記得是否比較勇敢」，而是「**當記得會害死仍活著的人時，你還有沒有權利要求完整的自己**」。
  - 七號是這句的變奏：**當找回某個人會害死仍活著的人時，你怎麼選**——他要賣掉網去找回妹妹，主角當年刪掉自己去保護網。兩人是同一道不可能選擇的正反解。
- **鐵則**：非英雄、不打倒企業、**系統永遠不會被推翻**。三個結局都不是勝利，差別只在「誰被記住、誰被保住、誰被你連累」。

## 2. 世界邏輯：把「刪除」做出牙齒

近未來，**身份是行政性的**。你的「註冊」是你存在的脊椎：租約靠它自動續、工作靠 AI 媒合、串流社群靠它存在。當 AI 為了「效率／整理」把一筆註冊判定為**冗餘**，這個人不會被殺，而是被**行政性抹除**：

- 租約自動終止（公寓 401 那張「自動化合約更新否則視為放棄」）
- 工作被零售終端接手（便利商店的阿達 / 店控機器人）
- 串流／紀錄被當「閒置冗餘資料」清掉（被刪的老歌《雨還沒停》）
- 名字從系統刷白 → 變成 **黑戶**：肉體活著、行政上死了，飄進地下道、街友聚落；**且失去一切家屬資格**（七號因此無權查詢妹妹）

這不是惡意設計，是像清快取一樣清掉多餘的人。

**賽博龐克的那一刀**：富人把這套武器化成服務。付錢把某人標記成「冗餘」＝安靜抹掉一個礙事的人；付錢抹掉自己＝遺忘、消失、重來。**遺忘是一種商品。**

**最狠的一環——主角的正職就是這套機器的手。** 系統下令刪人，現場留下殘渣：遺物、還在「記得」他的故障 AI（像還在覆誦阿達的販賣機）、沒清乾淨的終端。**善後員＝把殘渣抹掉、把還記得的機器 reset 的清潔工。系統開頭刪，善後員收尾刪。**

→ 主角的兩個身份是**同一個動作的正反面**：正職領錢把人抹乾淨，副業偷偷把正職該毀的東西藏起來。**拾遺者，是一個良心未泯的抹除者。**

### 保存也有代價（接 §6 Trace）

黑戶不是只需要被記得；他們也需要**不被系統重新找到**。主角作為拾遺者一直在保存痕跡，但**保存痕跡也可能替系統留下追蹤線**。

→ 拾遺不是天然正義。這條反過來刺中主角的副業，並成為 Trust/Trace 雙軸中 **Trace（系統追蹤風險）** 的世界觀根據（見 §6、§7 七號事件）。

## 3. 主角的真實過去

他曾是個受信任的善後員，拿得到富人區門禁。某次被派去富人區清一個「被服務性刪除」的人的殘渣——那人是夜總會賣「真人對話」的服務者（真人服務＝奢侈品），記得太多客戶的事，被付錢標記成冗餘。

**他清不下去。** 他留了她的殘響——這就是「拾遺者」副業的起點：他的第一件收藏，是他沒能救的人。而「留下不該留的東西」讓他自己也變成冗餘——下一張派工單，是抹掉他。

他先一步知道了，**沒有逃**。他自己走進遺忘服務，把自己刪成平民區黑戶。

### 自我刪除 = 逃 + 保護

不是只為了逃避痛苦而刪掉自己。他曾看過不該看的東西——**不只是富人的罪，而是那群仍活著黑戶的藏身方式**（見 §4 的「她」）。只要他被抓回系統，他的記憶就會變成追蹤線索。**所以他選擇刪掉自己，既是逃，也是保護。**

→ 開場失憶（已建）不是病，是他自己買的——而且是一個帶倫理重量的行動：他當年也許懦弱，但**不只是**懦弱。

> **把關**：保留**自利的邊**——他保護那個網，有一部分也是因為網一旦被抓，他自己的角色就曝光。別讓「保護別人」把他洗成高尚。罪責維持中檔。

### 罪責刻度：中檔

- 他是**抹除之手，但只是底層執行者**——照單抹人、從不決定抹誰。
- 罪是「**服從與旁觀**」（平庸之惡），不是主謀、不是惡意。
- 他**破過一次戒**（留了她的殘響），那正是他被標記的原因。
- **底線**：他是底層的手、不是下令的人。**不要往「重檔」（明知無辜還冷漠照抹）滑**。

### 罪責回扣縫進阿達：四段式揭露

把「主角親手抹過的人」縫進 **Phase 8 既有的阿達**（便利商店前店員 / 已成黑戶的前任店員），不發明新 NPC。主角不是阿達悲劇的唯一兇手，但他是行政抹除鏈條的**最後一隻手**。要讓玩家**先懷疑、再否認、最後無法否認**。四段在五幕中的落點見 §7（核心三段集中於 Act 2C）。

**第一段 · 店控機器人誤認（Act 1 後段 / Act 2A 開頭）**
> 「善後員編號確認中……歡迎回來。」
玩家當下只會以為是故障。

**第二段 · 阿達殘響描述「那個人」（Act 2C）**
> 「他穿雨衣。手上拿著維修棍。
> 他說只是照流程。
> 他說機器記得太多，對我不好。」
玩家開始懷疑，但還能逃避。

**第三段 · 舊善後工單揭露（鎖死 Act 2C，即 Act 2 後半）**
工單顯示對象＝阿達、處理項目＝戶籍刷白 / 員工權限移除 / 店控記憶重置 / 殘留人聲格式化、執行人＝主角失憶前身份。正式確認兇手是主角。
> **本機把關**：此段**鎖 Act 2C，不放 Act 4**。Act 4 已有「你自己的備份」大反轉，兩個「兇手是你」同幕落地會互相鈍化。

**第四段 · 阿達本人短暫登場（僅一次）**
**只出現一次、不對話樹、不跟隨、不變主線夥伴**。地點可為地下道深處、黑戶聚落邊緣或資料中心附近。不是來復仇：
> 「你忘了啊？
> 也好。
> 至少有人可以忘。」
守住中檔罪責（不復仇、不洗白）。

## 4. 情感結構：她 / 三張臉 / 晚 / 鹿

### 4.1 「她」——夜總會的真人對話者（行動者）

主線的情感引信。主角這幾個月一直無意識地帶著／追著她的碎片（Act 1 那一震就是撞到她）。拾遺者的收藏從她開始，他卻不記得她是誰。

她不是被抹掉的受害者，而是**用自己的刪除替別人遮蔽**的行動者：

- 她曾替地下道黑戶提供真人對話 / 假履歷 / 情緒資料 / 聲紋片段，幫他們**混過 AI 身份檢查**。
- 她**自願被刪**，為了讓**那批偽裝資料的來源一起從系統上消失**。
- 她留下的殘響不是「請記得我」，而是「**別把這份名單還給系統**」。
- 她保護的不是一個人，而是**一群黑戶互相偽裝出的生存網**——具體即 §4.2 的三張臉。

**她的核心殘響（Act 3 夜總會殘響房間，拍板台詞）**：不是求救、不是告白，是命令——
> 「你要是還在找我是誰，代表你還沒搞懂。
> 重點不是我。
> 重點是別讓他們被找到。」
把主線從「尋找她」正式轉成「接手她未完成的事」。

**fridging 修法**：她真的沒了（輓歌成立），但**有主體性**；與主角反轉**互為鏡子**；**沾一點 C**（伍姐記得她、小岑靠她的聲紋活著——一絲活著的餘溫）；**避開完整的 A**（不重逢、不乾淨救贖）。

> **把關**：名單 / 網是**賭注**；鏡頭永遠對著**她這個人**與她保護的**那三張臉**，不要變成「解一份檔案」。

### 4.2 三張臉：黑戶網具體化

「她」保護的不是抽象名單，而是三個玩家會實際見到、互動、甚至不一定喜歡的人。玩家最後保護的，是這三張仍活著的臉。

**小岑——靠假聲紋活下來的少年黑戶**
- 約 14–16 歲，住地下道邊緣，替聚落跑腿、偷零件、帶路；靠「她」留下的聲紋片段與假履歷偶爾混過低階 AI 身份檢查。
- 個性不討喜：嘴臭、防備、會偷主角東西。不是純潔受害者，是一個已被城市教壞的小孩。
- **功能**：讓玩家看見「她」保護的是未來，但這個未來不乾淨、不感人、也不會感謝你。
- **Protect 結局回收**：主角看見小岑安全通過一次身份檢查；小岑不認得他、甚至嫌他擋路。玩家知道自己保住了他，主角不知道。

**伍姐——前城市維修員，地下道的老維修人**
- 曾是城市基礎設施維修員，後被刷成黑戶；現管聚落電力、淨水、舊機器維修。知道很多「她」的事，但不神化她。
- **代表台詞**：「她不是好人。她只是比我們晚一點壞掉。」
- **功能**：防止「她」變成聖女。這世界的善意是從交易、恐懼、疲憊裡長出來的。

**七號——想把藏身網賣回系統，去確認妹妹是否還活著的人**
- 沒固定名字，大家叫他「七號」。曾被「她」救過。
- **核心動機（v2.2 拍板）**：他有一個**妹妹仍在系統內**；他作為黑戶**已失去家屬資格**，無權查詢她是否還活著、是否被轉移、是否仍被照護。他想把藏身網的一部分賣回系統，真正想換回的是——**查詢妹妹狀態的資格 / 家屬的行政承認 / 確認她還存在的權利**。
- → 他的背叛不再只是自私，而是**另一種找回某個人的執念**（主題變奏，見 §1）。
- **Act 2A 鋪墊台詞**（只提「有人掛在上面」，不明說妹妹）：
  > 「你們可以一直躲。
  > 我不行。
  > 我有一個名字還掛在上面。」
- **與 Act 3→4 小爆點的關係、三分支結果**：見 §7。

#### 4.2.1 關鍵道具：兒少照護補給回執

- **取得**：Act 2B 隧道清潔機戰鬥後的探索區（舊行政物流區 / 照護補給箱）。
- **表面**：像一張沒價值的行政物流單——某兒少照護機構的補給配送紀錄、模糊化收件代碼、營養包 / 學習終端耗材 / 冬季衣物、最近一次配送顯示成功、**沒有完整姓名**（玩家一開始看不出和七號有關）。可當雜物**賣給晚**。
- **真正用途**：七號能認出上面的機構代碼、舊暱稱、手寫符號或錯字。它足以證明——**妹妹仍在系統內、近期仍在接收照護補給、沒有被刷白 / 轉清 / 死亡登記**。它不保證她過得幸福，只證明**她還在、暫時安全**。對七號來說已經足夠。

> **把關（克制）**：妹妹永遠不登場（只是系統裡一筆照護紀錄）。「她還活著」絕不能寫成溫馨節拍——保持「不保證幸福，只證明還在」的冷度。對本作氣質而言，**這個克制比任何替補惡人都重要**。

#### 4.2.2 賣給晚的處理

若玩家把回執賣給晚，晚可給一句輕提醒，但不解謎、不阻止：
> 「這種回執沒什麼價。
> 除非你知道上面的代碼是誰的。」
玩家仍賣掉 → **無法觸發七號和平成功線**（賣＝親手丟掉自己不知道存在的東西，呼應 §6 清洗「你永遠不知道刪掉了多少」）。

#### 4.2.3 七號和平成功線（稀有恩典，不加路標）

- **定位拍板**：這是一條**稀有恩典**。漏斗很窄（持有回執 + 事件爆發前主動找七號 + 不威脅逼問 + 選擇交還），**第一輪大多數玩家會錯過——這是刻意的**，完全符合本作「你會錯過、且不知道錯過什麼」的氣質。**不加額外路標。**
- **觸發條件**：持有「兒少照護補給回執」；於七號背叛事件爆發前主動找七號對話；未以威脅 / 嘲諷 / 逼問推進；選擇把回執交給七號。
- **對話方向**（七號先不信、認出代碼後沉默崩裂、不大哭）：
  > 七號：「這哪來的？」
  > 主角：「地下道舊物流箱裡。」
  > 七號：「你看得懂上面寫什麼？」
  > 主角：「看不懂。」
  > 七號：「那你就不知道你拿著什麼。」
  > 主角：「所以我拿來問你。」
  >
  > 七號（確認妹妹仍在名單後）：
  > 「她還在。」「那我不能回去。」「我一回去，他們就會順著我找到她。」「……幹。」
- **結果**：七號自願放棄把藏身網交出去。但**不是溫馨和解**——他不立刻成為朋友、仍不完全信任主角、可能離開聚落一段時間 / 保持距離；伍姐 / 小岑對主角信任小幅上升；**給回執視為一次「還」**（Trust↑、Trace 不增或小幅下降，見 §6）。
  > 七號：「我欠你一次。
  > 不是欠你們。
  > 是欠你。」

#### 4.2.4 設計把關：七號同情化 = 世界軟一格，但醜陋搬進他本人

妹妹線給了七號正當理由，**接受世界在「沒有卡通壞蛋」這個層面軟一格**——但這不是變善良，而是把醜陋從「角色人設」搬進「系統壓力下普通人會做的事」：**一個愛妹妹的哥哥，準備把一個小孩（小岑）和伍姐的身份賣回系統。** 這比扁平叛徒更黑、更難脫鉤。為守住這層，四條守則：

1. **背叛要具體、不准美化**：明寫他要賣的是什麼——**小岑的位置、伍姐的舊身份**，不 fade-to-black 帶過。
2. **同情不能買掉後果**：在攔下 / 部分流出分支，七號**不被回溯赦免**——你知道他有妹妹，照樣得到一個怨恨你的人；小岑的暴露照樣是真的。理解 ≠ 原諒 ≠ 沒有代價。
3. **三張臉各守本職**：別讓伍姐 / 小岑去扛背叛質地（那現在是七號的「同情與醜陋並存」張力態）；伍姐繼續反神化、小岑繼續不討喜。
4. **（可選、低成本）留一小撮沒有救贖的灰**：一個質地鏡頭即可——聚落裡有人從屍體上扒東西、有人不肯分水——讓聚落不會整個變成一個擁抱。

### 4.3 晚——鏡子，不是獎品（含私心）

- 她比她說的更知道你是誰：可能早看穿你是個被刪的善後員。「等你值得了再一個字一個字給你」不是調情，是保護與試探。
- **她反對的不是你想知道真相**，而是**你把活人的安全拿去換自己的完整**——但不是她的全部理由。
- **Act 4 拉扯台詞（拍板）**：
  - 活人安全版：
    > 「你可以想起來。但你要先知道，你想起來以後，**誰會被你一起拖回系統裡**。」
  - 私心版（新增）：
    > 「我說是為了他們。
    > 可是也有一點，是為了我自己。
    > 你想起來以後，就不會是現在這個你了。」
- → 晚不是道德指南，而是一個也會害怕、也會自私、也想留下某個版本主角的人。
- **戀愛=可選支線**：不強制，但她的賭注染色結局（見 §8）。

### 4.4 鹿其琛——「還」的引路人＋平行對照

- 「還」的引路人：他母親的殘響（`echo_lu_family`，他不收不談）是錢買不回的記憶；主角能替他做他腿腳做不到的事。
- 主題的鏡子：一個用錢追趕遺忘、卻追不回自家的人。他不深度捲進主角祕密。
- **Trust/Trace 連動**：替鹿把母親那條還回去，要面對「會不會把某個原主重新納回系統追蹤」的微決定；可先「清洗」再還以壓低 Trace。

### 4.5 「還」母題鏈（v2.2 拍板）

三次「把某個人還給某個人」，由淺入深、最後反噬主角自己：

1. **鹿的母親**——替鹿還回他腿腳到不了的記憶。
2. **七號的妹妹**——替七號做到當年沒人替他做的事：給他「那個人還在」的證明（給回執＝一次「還」）。
3. **主角自己**——前兩個你都還得出去，**唯獨自己的完整還不回**。

→ 這條鏈**預示 Protect 結局**：你能把別人的人還給別人，最後卻把自己讓了出去。

## 5. 新增玩法系統：戰鬥 + 跳躍

> 戰鬥**服務主題（普通人、活下去）**，不是力量幻想。刻意笨拙、危險、不爽快。

### 5.1 戰鬥定位

- 戰鬥 = **生存與逃脫**，不得已、環境危險，刻意不賦能。
- 對手不是「壞人」，是**系統放出來的東西**：故障 / 野化清潔無人機、自動驅逐 / 執法機、搶殘渣的黑戶、資料中心低階保全。
- **撿來的棍子**（鋼筋 / 水管 / 報廢電擊棒），**不會壞**。主角**不擅長打鬥**；**無升級、無技能**。
- 高潮永遠是記憶揭露，不是打贏誰。

### 5.2 維修式「格式化重置」戰鬥（限機器敵人）

- **棍子弱傷害**：敲擊故障無人機 / 執法機，主要效果是**短暫癱瘓（Stun）/ 打斷動作**，而非直接消滅。
- **核心解法 = 格式化**：用**輕跳 + 走位繞到機器人後方 / 上方**，按住主互動鍵（E）進行**「強制格式化重置（Reset）」**。
- 玩法質感：藍領工人的維修與除錯，與善後員設定在操作上合一。

**邊界**：

- 「格式化重置」**只對機器人 / 無人機**成立。**對人類敵人**（搶殘渣的黑戶、保全）不能格式化 → 走**嚇退 / 撐過 / 對話 / 交易 / 環境阻隔 / 逃**。主角可揮棍自保，但不進入「打贏人」的玩法邏輯。
- **reset（戰鬥解）≠ defuse（非戰鬥解）**：支線預先「理解 / 修好 / 安撫」可讓某些敵人**根本不出現或變成不是敵人**；reset 是你沒解開時、當場制伏機器的退路。

### 5.3 失敗模型

- **沒有真正的「失敗態」、沒有 Game Over。**
- **打輸 = 岔到另一條故事線 / 任務解法。** 贏和輸都是有效路徑。
- 強制生存片段沒撐過 = 該段**軟重置**（回片段開頭），不掉東西。

### 5.4 戰鬥先做 Act 2B 一場原型

戰鬥不全面展開。第一階段只製作一場完整原型（位於 Act 2B），確認可玩後再擴張。

**Act 2B 戰鬥原型：隧道清潔機**
- 地點：廢棄地鐵隧道。敵人：故障清潔／驅逐機。
- 核心流程：①巡邏 → ②發現後追擊 → ③可逃跑 / 躲避 / 繞路 → ④棍子只造成短暫 stun → ⑤跳上平台或繞到背後 → ⑥按住 E 強制格式化重置 → ⑦成功後敵人進入低功率待機 → ⑧失敗不 Game Over，被迫掉入另一條路線。
- 戰鬥感受：笨拙、危險、勉強撐過，像藍領維修工處理失控機器。玩家不是英雄，只是剛好知道怎麼讓壞掉的東西安靜。
- **戰後**：開放舊物流箱 / 行政殘件 / 照護補給箱探索 → 可取得「兒少照護補給回執」（§4.2.1）。

### 5.5 戰鬥場景數量（長線目標）

- 全主線約 **2–3 個戰鬥場景**（不含主題型遭遇 P-00），各對應一張「新危險地圖」。
- 第一版只落地 Act 2B 原型；Act 3 / Act 4 戰鬥隨場景開工再做。

### 5.6 跳躍

- **jump = 探索 / 移動動詞，不是戰鬥動詞**（但在 §5.2 用於繞後）。
- 危險地圖輕度平台跨越（延續防火梯）；抵達隱藏採集點 / 替代路線；追逐片段逃 / 翻越。
- 手感樸素、寬容：短跳 + 抓邊緣，**無二段跳 / 蹬牆**。

## 6. `賣／留／還` → Trust / Trace 雙軸（+ 清洗）

`賣／留／還` 不再只是道德分數，背後是兩條**隱性狀態**（玩家不直接看到數值，從 NPC 反應、任務路線、結局染色感受）：**Trust（他人信任）** 與 **Trace（系統追蹤風險）**。

| 選擇 | 行為 | Trust | Trace | 世界觀意義 | 染色傾向 |
|---|---|---|---|---|---|
| **賣** | 把殘響賣掉換資源 / 錢 / 情報 / 通行 | 下降 | 下降（手上少一份可被追蹤的原始資料） | 你把別人的存在再次商品化 | Edited Expose（諷刺） |
| **留** | 把殘響保存在自己手上 | 矛盾 / 偏↓（晚理解你想記得、但不信你扛得住後果） | 上升（保存原始痕跡留追蹤線） | 情感保存最多、解鎖更多回憶 / 旁支 / 城市碎片 | Reclaim |
| **還** | 把殘響交還當事人 / 家屬 / 該有處置權的人 | 上升（某些 NPC 主動幫助） | 若未清洗敏感資料仍可能上升 | 把記憶的處置權還給別人 | Protect |

### 6.1 清洗：讓「還」不是固定正解

清洗殘響：刪定位 / 模糊聲紋 / 移除原始系統標記 / 只留情感內容。清洗後再「還」：Trust↑、Trace 較低。**代價**：損失部分真相，**玩家永遠無法知道自己刪掉了多少細節**。

### 6.2 給回執 = 一次「還」（v2.2 拍板）

把「兒少照護補給回執」交給七號，在機制上是一次 **`還`**——把證明「某個人還在」的東西，交還給該擁有它的人：**Trust↑、Trace 不增或小幅下降**。與「替鹿還母親殘響」並列為「還」的兩個具體特例（見 §4.5 還母題鏈）。反之賣給晚＝一次 `賣`（Trust / Trace 皆下降），且鎖死和平線。

### 6.3 落地順序（build order，已拍板）

第一版只實作 **Trace 單軸 + 清洗**（追蹤風險是主線賭注的核心齒輪，程式無現成等價物，必須新建），**Trust 暫用既有 `affinity` 系統近似**；待原型站穩、需要「社群層級信任 vs 逐個 NPC 好感」的細膩度時，再把 Trust 獨立成專軸。此為 build order 拍板，不改雙軸設計。

## 7. 五幕結構 × 8–10 小時分配（Act 2 拆 2A–2D、含七號小爆點）

> 目標：純玩主線約 **8–10 小時**，不含全部探索。每張「新危險地圖」配一場戰鬥＝離開安全平民區的「危險簽名」。

| 幕 | 場景 | 主線時長 | 戰鬥 | 敘事重心 | 自我碎片（旗標漸解） |
|---|---|---|---|---|---|
| **1** | 平民區（**已建** + 鉤子） | ~1h | 無 | 接地、撞到「她」碎片、鹿說「從線上面下來的」、晚瞥見失神；**阿達①店控誤認** | 莫名一震（不知為何） |
| **2** | 地鐵站 + 地下道 / 街友聚落（新；拆 2A–2D） | ~2–2.5h | **戰鬥①**（2B） | 見下方四段 | 你以前往上通勤；黑戶半認得你；**你親手抹過阿達** |
| **3** | 富人區夜總會（新；第一版至少 15–20min 殘響房間核心片段） | ~2–2.5h | **戰鬥②** 保全（人類：潛行 / 撐過） | 刪除是富人買得起的服務；管家 AI 覆誦醜聞；**她的核心殘響「別讓他們被找到」** | 你曾上來清過一個人；你看到的是那群黑戶的藏身方式 |

### 7.1 Act 2 拆段（2A / 2B / 2C / 2D）

因 Act 2 承擔聚落 + 三張臉 + 戰鬥原型 + 阿達罪責 + 七號妹妹線，拆四段避免資訊與情緒過載：

- **2A — 第一次進地下道，認識三張臉**：打開世界、理解被刪的人仍活著、認識小岑 / 伍姐 / 七號；七號初步提「系統內仍有一個重要的人」但不明說妹妹（§4.2 台詞）。
- **2B — 隧道清潔機戰鬥 + 取得回執**：第一場格式化重置原型（§5.4）；戰後探索取得「兒少照護補給回執」，此時**不標註為七號相關**，只是可保留 / 可賣的雜物。
- **2C — 阿達罪責揭露**：阿達殘響 + 舊善後工單，確認主角是抹除鏈最後一隻手（§3 第二、三段）。**此段獨立給足情緒重量，不與七號和平線重疊**，避免兩個爆點互相搶戲。
- **2D — 回到聚落，七號可選對話**：玩家可賣回執給晚，或帶回執找七號（觸發稀有恩典和平線）；未處理則七號事件仍在 Act 3→4 爆發。此段是 Act 2 收束，也是 Act 3→4 爆點的提前埋雷。

> **節奏把關**：2C（阿達，向內、最重）→ 2D（七號，向外、可選且稀有）的順序，讓兩個重節拍錯開；和平線本身可錯過，進一步分散情緒負載。

### 7.2 七號小爆點：三分支（Act 3→4 過場）

- **引爆物**：七號試圖把藏身網一部分交給系統，換回確認妹妹的資格——不是惡意，是另一種求生（§4.2）。
- **Trace 連動**：玩家長期「留」太多未清洗殘響 → Trace 高 → 七號更容易拼出整張網、可挽回空間更小；玩家「還」得夠 / Trust 夠 → 伍姐或小岑**提前警告**主角。
- **玩法**：沿用既有系統——對話 / 威嚇 / 交易（人類衝突，不格式化）+ 追逐 / 翻越（§5.6）。**不一定新增一場正式戰鬥**。

**三分支（不採用「完全沒攔下大災難」線）**：

| 分支 | 觸發 | 後果 |
|---|---|---|
| **D · 和平成功** | 事件爆發前，用回執讓七號自願放棄（稀有恩典，§4.2.3） | 藏身網沒流出；七號不成朋友但不再主動背叛；聚落壓力最低；伍姐 / 小岑可能提前幫助；Act 4 壓力較低，但系統仍可能因其他 Trace 線索逼近 |
| **A · 成功攔下** | 沒觸發和平線，但事件爆發後成功攔下七號 | 藏身網沒完整流出；七號怨恨主角；聚落暫安全但內部裂痕加深；Trust 不一定上升（你只阻止災難、沒理解他）；Act 4 正常推進 |
| **B · 部分攔下** | 沒完全阻止，或 Trace 過高致七號已拼出部分資料 | 系統取得一部分線索；小岑或伍姐其一暴露風險上升；Act 4 可見某些檔案被重新標記；結局染色更黑；**仍不直接導致大型 NPC 死亡或主線斷裂** |

**為何不做「完全沒攔下大災難」**：避免一次任務失敗承受過大懲罰；避免七號事件喧賓奪主蓋過 Act 4 自我備份反轉；避免主線突然變拯救聚落英雄劇；守住核心氣質——**失敗改變染色與代價，但不把玩家推進懲罰性壞線**（與 §5.3 一致）。

### 7.3 設計重點

- 「**還**」在 Act 4 從伏筆變真流程，且**帶 Trace 風險**：替鹿把母親那條還回去＝道德軸高潮，但也要面對「會不會把原主重新納回系統追蹤」（可先清洗）。
- 建議新增場景補鏈：地鐵 → 地下道 / 街友聚落 → 富人區夜總會 → AI 資料中心 →（可選）地下廣播站（「公開」結局出口）／ 廢屋檔案室（可能藏 P-00）。

## 8. 三結局（Codex 軸 + v1 人味 + Gemini 後果 + 加痛）

三條共用觸發點：**Act 4 備份區，你站在自己的備份前**——那個「被刪之前的你」。你已經知道：不是別人刪了你，是你自己選的，而且是為了保護那個網。

**軸**：你最後不是選真相或謊言，而是**選誰有權擁有哪一部分真相**。
**前景**：每條結局的情感落點掛在**具體的人**（她、三張臉、鹿母、阿達、晚）。
**後果**：Trust/Trace 累積決定哪條「配得上」並染色；**傾向只染色 + 少量軟門檻，不硬鎖**。
共用收尾畫面：雨、那首老歌《雨還沒停》、灰裡的一點橙。

### 拿回自己（Reclaim）——最重、最自私

你把備份上傳回自己，想起**全部**：抹除之手、你親手清掉的阿達、「她」、那樁罪。你完整了——然後被記憶壓垮。**但你也重新帶回一組會害死黑戶的可追蹤真相。** 完整自己，是拿別人的安全去換的。

- **遊戲拒絕救贖**：想起來修不好任何事，只是多一個人扛著重量、且多一份危險。
- **晚**：最痛。你變回那個抹除者——正中她的賭注。回到公寓後晚徹底失望、消失，後續地圖不再出現。
- **配得上**：偏「**留**」、Trust 低 / Trace 高的玩家。

### 保住別人（Protect）——最「活下去」、主動的犧牲（加痛，不是 Good Ending）

你親手刪掉自己的備份。你**刻意**繼續當忘了的拾遺者——為了保護那個網主動放棄，連「知道自己為何這麼做」的權利都放棄。保留溫度，但加回不可修復的痛：

- **小岑回收**：你看見小岑安全通過一次低階身份檢查、沒被系統抓回。但他不認得你、甚至嫌你擋路——「大叔，站那邊幹嘛？雨很大欸。」玩家知道主角成功了；主角不知道。
- **晚的餘溫保留，但不能太甜**：她仍可出現在公寓窗邊看雨，但不是戀愛獎勵、不是圓滿。「你又變回來了。」／主角：「變回什麼？」／晚看著雨，沒有回答。
- **阿達無法被修復**：即使保住黑戶網，阿達那件事仍然發生過。阿達不會原諒他；或更狠——他根本不在乎原不原諒。
- **七號（若走過和平線）**：他留下＝又一張臉保住；呼應 §4.5 還母題鏈——你能把別人的人還給別人，最後卻把自己讓了出去。
- **配得上**：偏「**還**」、Trust 高的玩家。

### 刪改後公開（Edited Expose）——最黑、握著刀

你把過去 + 遺忘服務的證據 + 殘響上傳地下廣播。不是扳倒誰（扳不倒），只是**留底**。但**公開 ≠ 全公開**：你必須決定**是否刪去能指向活人的部分**。

- **更黑的演出**：廣播化成雜訊、也許沒人聽、也許不久被當冗餘清掉；隔天你照樣上工；系統根本不在乎。**你以為在選，系統毫不在意。**
- **軟門檻**：必須在遊戲中「**還**」了足夠殘響（Trust / 清洗到位），才能解開加密並發送；**還得太少 → 公開被系統靜默攔截、完全無效**，呈現極致虛無。
- 改變的只有：某處、某幾個人，有那麼一刻記得了。**海裡的一滴漏。**
- **配得上**：偏「**賣**」的玩家別有諷刺——把記憶當商品賣掉的人，最後把整個市場、連自己一起，（刪改後）攤開給所有人看。

> 三條共用收尾：「雨還沒停，街上的燈已經熄了。」差別只在：**這一刻，是誰在記得、誰被保住、誰被你連累。**

## 9. 隱藏內容：P-00 主題型遭遇（暫緩、非力量挑戰）

隱藏 boss 不在第一階段拍板成正式戰鬥。若保留，定位改為**主題型遭遇**。

**總清機 P-00**：一台舊型善後機器，曾協助處理大量被刪除者的殘留資料。沒有強烈敵意，只是壞掉後不斷重複過去的清理流程。它像主角的機械鏡像——都是善後工具、都曾把人抹乾淨、都殘留了不該留下的記憶、都不知道自己算不算有罪。

**遭遇方式**（不是單純打贏，而是選擇如何處理它）：

1. **Reset 它**：讓它安靜，停止痛苦，也停止記得。
2. **留著它**：保存它體內所有被格式化過的殘響，但 Trace 大幅上升。
3. **還 / 公開它的資料**：把部分紀錄交給地下廣播或相關家屬，但可能暴露仍活著的人。

**落地**：不必放進第一版主線；適合作為後期支線、隱藏區域，或資料中心旁支內容（候選位置：廢屋檔案室）。

## 11. 開發順序與規模

- **建議 build order**：先打通脊椎 **Act 1 → 2 → 4 → 結局**（精瘦主線）；**Act 3 至少保留 15–20min 夜總會核心片段**（不可完全跳過），完整富人區後置為第二批。戰鬥先做 **Act 2B 隧道清潔機原型**；Trust/Trace 先做 **Trace 單軸 + 清洗**。Act 2 內部按 2A→2B→2C→2D 順序實作。只影響開發順序，不影響完整五幕拍板。
- **七號妹妹線的 scope**：妹妹**永不登場**（只是系統一筆紀錄），實際新增成本＝一件關鍵物件 + 一段可選和平對話 + 三分支結果旗標，相對划算。
- **規模現實（已接受）**：要做完整個主線，規模勢必擴大——3 張新場景 + 新戰鬥 + 新跳躍 + 雙軸狀態 + 數個新 NPC ＝好幾個 Phase（Phase 11+）。本檔是排序好的長線藍圖，落地時須拆 Phase。

## 12. 已拍板 vs 待拍板

### 已拍板（v2.2）

- 最終反轉：**你自己選擇被刪**（既是逃也是保護）。
- 主角罪責：**中檔**（底層執行之手、服從旁觀、破戒過一次；保留自利的邊）。
- 罪責回扣：**阿達四段式揭露**；**舊工單鎖死 Act 2C**；阿達本人**僅登場一次**。
- 「她」：**行動者——用自我刪除保護黑戶藏身網**；核心殘響「別讓他們被找到」鎖 Act 3 夜總會片段。
- 黑戶網具體化：**小岑 / 伍姐 / 七號**三張臉。
- **七號妹妹線**：妹妹仍在系統內、七號無資格確認；**回執**證明她還在；回執表面像雜物、可賣給晚。
- **七號和平成功線＝稀有恩典，不加路標**；給回執＝一次「還」（Trust↑ / Trace 不升或微降）。
- **七號事件三分支**：和平成功 / 成功攔下 / 部分攔下；**不採用完全沒攔下大災難線**。
- **七號同情化把關**：接受世界軟一格、醜陋搬進七號本人；四條守則（背叛具體、同情不買後果、三張臉各守本職、可選留一撮無救贖的灰）；妹妹揭露保持克制、不寫成溫馨。
- **「還」母題鏈**：鹿母 → 七號妹妹 → 主角自己，預示 Protect 結局。
- 晚：**可選戀愛、染色結局、不強制**；台詞「誰會被你拖回系統」**＋私心版本**。
- 戰鬥：**生存 / 不爽快 / 無升級無技能 / 棍子不壞 / 維修式格式化重置（限機器）/ 人類衝突不格式化 / 輸=岔故事線 / 先做 Act 2B 一場原型 / 長線約 2–3 場**。
- 跳躍：**探索移動為主、樸素、無二段跳 / 蹬牆**（戰鬥用於繞後）。
- 道德軸：**`賣／留／還` → Trust / Trace 雙軸 + 清洗**；傾向只染色 + 少量軟門檻；**落地「Trace 單軸 + 清洗」先行、Trust 暫用 affinity 近似**。
- 小爆點：**七號背叛**，Act 3→4 過場，point of no return。
- **Act 2 拆 2A / 2B / 2C / 2D**。
- 三結局：**拿回自己 / 保住別人（加痛、非 Good Ending）/ 刪改公開**；共用收尾畫面。
- 《雨還沒停》歌：**城市記憶母題 / 地下道共同歌**，不綁「她」或主角身世。
- 隱藏內容：**P-00 主題型遭遇**（暫緩、非力量挑戰）。
- 五幕 × 8–10h 分配：見 §7。

### 待拍板 / 開放問題（非阻斷，可後續收）

1. **「她」本人的身份細節**：名字、與晚 / 鹿是否有交集（三張臉已解掉「網」的具體化，但她自己仍空著）；是否與七號妹妹有任何隱性連結（目前不預設）。
2. **地下廣播站**（「公開」結局出口）是否升為正式場景；**廢屋檔案室**是否作為 P-00 候選場景。
3. **三結局是否任何一條都不硬鎖**：傾向只染色 + 軟門檻，需最終確認沒有結局被 Trust/Trace 硬性上鎖。
4. **七號三分支的細節數值**：B（部分攔下）暴露的是小岑還是伍姐、如何在 Act 4 與結局染色具體呈現。
5. **若要讓《雨還沒停》升格為主線線索**：需另建它與主角記憶 / 某活人命運的因果橋；目前不預設。
