## 1. 一句話 / 主題句

- **Logline**：一個替 AI 收屍的人，在收屍時不斷撿到「被刪掉的人」的碎片——最後發現，當初選擇被刪掉的人，是他自己。
- **主題句**：不是「記得是否比較勇敢」，而是「**當記得會害死仍活著的人時，你還有沒有權利要求完整的自己**」。
  - 七號是這句的變奏：**當找回某個人會害死仍活著的人時，你怎麼選**——他要賣掉網去找回妹妹，主角當年刪掉自己去保護網。兩人是同一道不可能選擇的正反解。
- **鐵則**：非英雄、不打倒企業、**系統永遠不會被推翻**。三個結局都不是勝利，差別只在「誰被記住、誰被保住、誰被你連累」。

## 2. 世界邏輯：把「刪除」做出牙齒

近未來，**身份是行政性的**。當 AI 為了「效率／整理」把一筆註冊判定為**冗餘**，這個人不會被殺，而是被**行政性抹除**：

- 租約自動終止（公寓 401 室前住戶那張「自動化合約更新否則視為放棄」——拒絕數位升級、被遷走的鄰居，留下的舊照片成為主角副業收藏裡的一條殘響）
- 工作被零售終端接手（便利商店的阿達 / 店控機器人）
- 串流／紀錄被當「閒置冗餘資料」清掉（被刪的老歌《雨還沒停》）
- 名字從系統刷白 → 變成 **黑戶**：肉體活著、行政上死了；**且失去一切家屬資格**（七號因此無權查妹妹）

**賽博龐克的那一刀**：富人把這套武器化成服務。付錢抹掉一個礙事的人，或付錢抹掉自己。**遺忘是一種商品。**

**最狠的一環——主角的正職就是這套機器的手。** 善後員＝把殘渣抹掉、把還記得的機器 reset 的清潔工。系統開頭刪，善後員收尾刪。→ 拾遺者，是一個良心未泯的抹除者。而保存痕跡**也可能替系統留下追蹤線**——這是 Trace 的世界觀根據。

### 歌曲（v2.3 拍板：拆兩首）

- **《雨還沒停》＝環境母題，不升格**：作為普通的城市記憶殘響（地鐵卡帶、街友哼唱），承擔世界觀的 Riso / Zine 舊物情緒。不綁林霏或主角身世。
- **主線主題歌＝另一首全新歌曲、女聲（林霏的聲音）**：擔任主角的記憶鑰匙與主線核心情感載體。歌名與細節後議（見 §12）。

## 3. 主角的真實過去

他曾是受信任的善後員。某次被派去富人區清一個「被服務性刪除」的人的殘渣——那人是夜總會賣「真人對話」的服務者**林霏**，記得太多客戶的事，被付錢標記成冗餘。

**他清不下去。** 他留了林霏的殘響——拾遺者副業的起點，第一件收藏是他沒能救的人。「留下不該留的東西」讓他也變成冗餘，下一張派工單是抹掉他。

他先知道了，**沒有逃**。他自己走進遺忘服務，把自己刪成黑戶。**自我刪除＝逃 + 保護**：他看過那群黑戶的藏身方式，只要被抓回系統，他的記憶就變追蹤線。

### 罪責刻度：中檔（已拍板）

- **抹除之手，但只是底層執行者**——照單抹人、從不決定抹誰。罪是「服從與旁觀」（平庸之惡）。
- **破過一次戒**（留了林霏的殘響）——那正是他被標記的原因。
- **保留自利的邊**：他保護網，一部分也因為網一旦被抓、他自己的角色就曝光。別洗成高尚。
- **底線**：底層的手、不是下令的人。不要往「重檔」滑。

### 罪責回扣縫進阿達：四段式揭露

①店控機器人誤認（Act 1 後段 / 2A）→ ②阿達殘響「他穿雨衣、拿維修棍、說只是照流程」（Act 2C）→ ③舊善後工單（**鎖 Act 2C**，確認執行人＝失憶前的主角）→ ④阿達本人短暫登場一次「你忘了啊？也好。至少有人可以忘」。把③鎖死 Act 2C、不放 Act 4，避免和「你自己的備份」兩個「兇手是你」同幕互鈍化。

## 4. 情感結構：林霏 / 三張臉 / 晚 / 鹿

### 4.1 林霏（Lin Fei）——夜總會真人對話者，行動者，非聖女

主線的情感引信。主角這幾個月一直無意識地帶著她的殘響（Act 1 那一震就是撞到她）。第一件收藏從她開始，他卻不記得她是誰。

**去聖母化（v2.3 拍板）**：林霏不是被抹掉的純潔受害者，也不是聖女。她做假身份、賣聲紋、包裝情緒資料——**她跑的是「偷來的富人數據 → 黑戶假身份」的洗白生意**，最初也是為了錢、為了活。她只是比聚落裡的人晚一點壞掉。

但她也**自願被刪、替別人遮蔽**：

- 她替地下道黑戶提供真人對話 / 假履歷 / 情緒資料 / 聲紋片段，幫他們**混過 AI 身份檢查**（小岑能過檢查，就是靠她的假聲紋）。
- 那批偽裝資料的**源頭是她**；只要她還在系統上，順著她就能把整群人挖出來。事情**敗露**後，她**自願走進遺忘服務、把自己連根刪掉**，讓這條線斷在她身上。
- 她留下的殘響不是「請記得我」，而是命令——「**別把這份名單，還給系統。**」

**她的核心殘響（Act 3 夜總會殘響房間，拍板台詞）**：
> 「你要是還在找我是誰，代表你還沒搞懂。重點不是我。重點是別讓他們被找到。」

**fridging 修法**：真的沒了（輓歌成立），但**有主體性**（自願被刪、有意圖、跑過自己的生意）；與主角反轉**互為鏡子**；沾一點 C（伍姐記得她、小岑靠她活著）；避開完整的 A（不重逢、不乾淨救贖）。

> **名字的不對稱**：林霏被人記得（有名），主角的名字被系統刷白（無名，只在備份前露出一次又放棄）。**她被記得、他消失**——強化 Protect 結局。

### 4.1.1 林霏 ↔ 七號的交易因果鏈（v2.3 核心新增）

這條鏈把「她」「七號妹妹」「回執」三件事綁成一條因果，去掉巧合感：

1. **交易**：七號當年是林霏工作的夜總會的**低階保安 / 清潔工**。他妹妹面臨被系統標記「冗餘」清除。七號為救她，利用職務之便**替林霏竊取夜總會 VIP 客戶的加密門禁卡與隱私數據**——這些後來成了林霏做黑戶假身份網的原料。
2. **對價**：林霏答應利用偽造技術，**把七號的妹妹塞進「兒少照護補給名單」**以求溫飽。
3. **致命斷聯**：林霏**偽造成功**，但**還沒把具體結果與機構代碼告訴七號，就因事情敗露而被迫自刪（失憶／消失）**。
4. **後果**：七號知道交易做了，卻**完全不知道成沒成、妹妹被分到哪個機構、是否還活著**。這份焦慮，就是他 Act 3→4 鋌而走險、想用部分藏身網換「確認妹妹資格」的**核心背叛動機**。

> **反諷**：七號要賣的網，有一部分正是他自己當年流血偷來、親手幫忙建起的。

### 4.2 三張臉：黑戶網具體化

**小岑——靠林霏假聲紋活下來的少年黑戶**
- 約 14–16 歲，住地下道邊緣，跑腿、偷零件、帶路；靠林霏的假聲紋偶爾混過低階身份檢查。
- 個性不討喜：嘴臭、防備、會偷主角東西。不是純潔受害者，是已被城市教壞的小孩。
- **Protect 結局回收（條件式，見 §8）**：若七號事件沒走到 Branch B，結尾主角看見小岑安全通過一次身份檢查、卻不認得他、甚至嫌他擋路。玩家知道自己保住了他，主角不知道。

**伍姐——前城市維修員，地下道的老維修人**
- 管聚落電力、淨水、舊機器維修。知道很多林霏的事，但不神化她。
- **代表台詞**：「她不是好人。她只是比我們晚一點壞掉。」
- **功能**：防止林霏變成聖女。

**七號——夜總會前保安，想換回確認妹妹是否還活著的資格**
- 沒固定名字，大家叫他「七號」。曾是夜總會低階保安 / 清潔工，與林霏有 §4.1.1 的交易。
- **核心動機**：妹妹仍在系統內、他作為黑戶已失去家屬資格、且因致命斷聯不知妹妹下落 → 想用部分藏身網換「確認妹妹的資格」。
- **Act 2A 鋪墊台詞**（只提「有人掛在上面」，不明說妹妹）：「你們可以一直躲。我不行。我有一個名字還掛在上面。」
- 三分支結果見 §7。

#### 4.2.1 關鍵道具：兒少照護補給回執（＝林霏未送出的遺物）

- **本質（v2.3 升級）**：這正是**林霏當年交易成功、卻未能交給七號的實體證據**——所以它才會以一張「沒人認領的行政物流單」之姿，漂在 Act 2B 的失物物流箱裡。
- **取得**：Act 2B 隧道清潔機戰鬥後的探索區。
- **表面**：像沒價值的物流單——配送紀錄、模糊化收件代碼、營養包 / 學習終端耗材 / 冬季衣物、最近一次配送「成功」、**沒有完整姓名**（玩家一開始看不出和七號有關）。可當雜物賣給晚。
- **真正用途**：七號能認出機構代碼、舊暱稱、手寫符號或錯字。它證明——妹妹仍在系統內、近期仍在收照護補給、沒被刷白 / 死亡登記。**它不保證她幸福，只證明她還在、暫時安全。對七號來說已經足夠。**

> **把關（克制）**：妹妹永不登場（只是系統一筆紀錄）。「她還活著」絕不能寫成溫馨節拍——守住「不保證幸福、只證明還在」的冷度。

#### 4.2.2 賣給晚的處理

賣回執給晚，晚輕提醒不阻止：「這種回執沒什麼價。除非你知道上面的代碼是誰的。」仍賣掉 → Trust / Trace 皆降，**鎖死和平線**（呼應清洗「你永遠不知道自己丟掉了什麼」）。

#### 4.2.3 七號和平成功線（稀有恩典，不加路標）

- **定位**：稀有恩典。漏斗很窄（持有回執 + 事件爆發前主動找七號 + 不威脅逼問 + 選擇交還），**第一輪多數玩家會錯過——這是刻意的**，不加路標。
- **對話**：七號先不信 →「那你就不知道你拿著什麼。」→「所以我拿來問你。」→ 認出代碼後沉默崩裂：「她還在。」「那我不能回去。」「我一回去，他們就會順著我找到她。」「……幹。」這是七號**第一次確知妹妹還活著且被林霏成功保護**。
- **結果**：他自願放棄交網。**不是溫馨和解**——不立刻成朋友、仍不全信你、可能離開聚落一段時間。留下：「我欠你一次。不是欠你們。是欠你。」給回執視為一次「還」（Trust↑、Trace 不增或微降）。

#### 4.2.4 設計把關：七號同情化 = 世界軟一格，但醜陋搬進他本人

接受「沒有卡通壞蛋」，但這不是變善良，而是把醜陋從「角色人設」搬進「系統壓力下普通人會做的事」：**一個愛妹妹的哥哥，準備把一個小孩（小岑）和伍姐的身份賣回系統。** 四條守則：①背叛要具體、不准美化（明寫他要賣小岑的位置、伍姐的舊身份）；②同情不能買掉後果（攔下 / 部分流出分支不回溯赦免）；③三張臉各守本職；④（可選）留一撮無救贖的灰。

### 4.3 晚——鏡子，不是獎品（含私心）

- 她比她說的更知道你是誰：可能早看穿你是個被刪的善後員。「等你值得了再一個字一個字給你」是保護與試探。
- **Act 4 拉扯台詞**：活人安全版「你想起來以後，誰會被你一起拖回系統裡」＋私心版「我說是為了他們。可是也有一點，是為了我自己。你想起來以後，就不會是現在這個你了。」
- **戀愛=可選支線**：不強制，但她的賭注染色結局（見 §8）。

### 4.4 鹿其琛——「還」的引路人＋平行對照

母親殘響（`echo_lu_family`）是錢買不回的記憶；替他還回去＝道德軸高潮，但要面對「會不會把原主重新納回系統」（可先清洗）。

### 4.5 「還」母題鏈

鹿的母親 → 七號的妹妹 → 主角自己。前兩個都還得出去，唯獨自己的完整還不回。**預示 Protect 結局**。

## 5. 新增玩法系統：戰鬥 + 跳躍

- **維修式格式化重置（限機器）**：棍子只 stun；核心解＝輕跳繞後 + 按住 E 強制格式化重置。**人類敵人不格式化**（嚇退 / 交易 / 環境阻隔 / 逃）。**輸 = 岔到另一條故事線**，無 Game Over。**撿來的棍子不會壞、無升級無技能**。
- **先做 Act 2B 一場原型**（隧道清潔機），可玩再擴張；長線約 2–3 場。
- **跳躍＝探索 / 移動動詞**（戰鬥僅用於繞後）：輕度平台跨越、抵達採集點、追逐翻越；短跳 + 抓邊緣，**無二段跳 / 蹬牆**。

## 6. `賣／留／還` → Trust / Trace 雙軸（+ 清洗）

兩條隱性狀態：**Trust（他人信任）**、**Trace（系統追蹤風險）**，獨立的兩軸。

| 選擇 | Trust | Trace | 世界觀意義 | 染色傾向 |
|---|---|---|---|---|
| **賣** | ↓ | ↓（原始資料離手） | 把別人的存在再次商品化 | Edited Expose（諷刺） |
| **留** | 矛盾 / 偏↓ | ↑（保存即留線） | 情感保存最多、解鎖最多回憶 | Reclaim |
| **還** | ↑ | 未清洗仍可能↑ | 把記憶的處置權還給別人 | Protect |

- **清洗**：刪定位 / 模糊聲紋 / 移除系統標記 / 只留情感內容。清洗後再還 → Trust↑、Trace 較低。**代價**：損失部分真相，**你永遠無法知道自己刪掉了多少細節**。清洗機制在 **Expose 結局**直接兌現（見 §8）。
- **給回執 = 一次「還」**：Trust↑、Trace 不增或微降；與「替鹿還母親殘響」並列。
- **落地順序（已拍板）**：第一版「**Trace 單軸 + 清洗**」先行，**Trust 暫用既有 `affinity` 近似**，等需要社群層級信任的細膩度再獨立。

## 7. 五幕結構 × 8–10 小時（Act 2 拆 2A–2D、含七號小爆點）

| 幕 | 場景 | 時長 | 戰鬥 | 敘事重心 / 自我碎片 |
|---|---|---|---|---|
| **1** | 平民區（已建 + 鉤子） | ~1h | 無 | 撞到林霏的碎片、鹿說「從線上面下來的」、晚瞥見失神；阿達①店控誤認。碎片：莫名一震 |
| **2** | 地鐵 + 地下道 / 街友聚落（拆 2A–2D） | ~2–2.5h | **戰鬥①**（2B） | 見 §7.1。碎片：你以前往上通勤；你親手抹過阿達 |
| **3** | 富人區夜總會（至少 15–20min 殘響房間） | ~2–2.5h | **戰鬥②** 保全（人類：潛行 / 撐過） | 刪除是富人買得起的服務；林霏的核心殘響「別讓他們被找到」；**這裡是林霏與七號交易的舊場**。碎片：你看到的是黑戶藏身方式 |
| **3→4 過場** | **小爆點：七號背叛** | ~0.3–0.5h | 視解法 | 七號要把藏身網一部分賣回系統換確認妹妹的資格 → 三張臉即將曝光；三分支見 §7.2 |
| **4** | AI 資料中心 · 備份區（climax） | ~2–2.5h | **戰鬥③** 低階保全（撐過 / 跑到門） | 善後員合法門禁進入（反諷）；橙＝唯一暖色；晚拉扯（含私心）；阿達④本人登場一次。碎片：**真相——你自己選擇被刪，是為了保護那個網** |
| **5** | 結局 | ~0.5–1h | 無 | 系統照常運轉。拿回自己 / 保住別人 / 刪改公開（§8） |

### 7.1 Act 2 拆段（2A / 2B / 2C / 2D）

- **2A 認識三張臉**：打開世界、被刪的人仍活著；認識小岑 / 伍姐 / 七號；七號提「我有一個名字還掛在上面」（不明說妹妹）。
- **2B 戰鬥原型 + 取得回執**：隧道清潔機格式化重置原型；戰後探索撿到回執（此時只是雜物）。
- **2C 阿達罪責揭露**：阿達殘響 + 舊工單，確認兇手是你。獨立給足情緒重量，不與七號線重疊。
- **2D 七號可選對話**：賣回執給晚，或帶回執找七號（觸發稀有恩典和平線）；未處理則七號事件仍在 Act 3→4 爆發。Act 3→4 爆點的提前埋雷。

### 7.2 七號小爆點：三分支（不採用「完全沒攔下大災難」線）

- **Trace 連動**：留太多 → 七號更容易拼出網；還得夠 / Trust 夠 → 伍姐或小岑提前警告。
- **玩法**：對話 / 威嚇 / 交易（人類不格式化）+ 追逐 / 翻越。不一定新增正式戰鬥。

| 分支 | 觸發 | 後果 |
|---|---|---|
| **D · 和平成功** | 事件前用回執讓七號自願放棄（稀有恩典） | 網沒流出；七號不成朋友但不再背叛；聚落壓力最低；Act 4 壓力較低，但系統仍可能因其他 Trace 線索逼近 |
| **A · 成功攔下** | 沒觸發和平線，但事件爆發後攔下他 | 網沒完整流出；七號怨恨你；聚落暫安全但裂痕加深；Trust 不一定上升；Act 4 正常推進 |
| **B · 部分攔下** | 沒完全阻止，或 Trace 過高致他已拼出部分 | **小岑承擔代價**：七號洩露的部分線索使**小岑的聲紋暴露**。Act 4 開始，玩家發現**小岑的帳篷空了，地上散落被踩壞的零件**。Act 4 可見檔案被重新標記；結局更黑；**仍不導致主線斷裂** |

> **不做大災難線**：避免一次失敗過大懲罰、避免喧賓奪主蓋過 Act 4 自我反轉、避免主線變拯救聚落英雄劇。失敗改變染色與代價，但不推進懲罰性壞線。

## 8. 三結局

共用觸發點：Act 4 備份區，你站在**自己的備份**前。軸＝你選誰有權擁有哪一部分真相；前景＝掛在具體的人；後果＝Trust / Trace 染色。

> **硬鎖規則（v2.3 拍板）**：**Reclaim / Protect 傾向只染色、不硬鎖**；**Expose 例外——用 Trace + 清洗 硬分判成 A / B / C**（見下）。

### 拿回自己（Reclaim）——最重、最自私

上傳備份回自己，想起**全部**——然後被記憶壓垮。**但你也帶回一組會害死黑戶的可追蹤真相。** 遊戲拒絕救贖：想起來修不好任何事，只是多一個人扛重量、且多一份危險。晚：最痛，你變回那個抹除者——正中她的賭注，回公寓後她徹底失望、消失。配得上：偏「留」、Trust 低 / Trace 高。

### 保住別人（Protect）——加痛，不是 Good Ending

親手刪掉自己的備份，**刻意**繼續當忘了的拾遺者，為保護那個網主動放棄，連「知道自己為何這麼做」的權利都放棄。保留溫度，但加回不可修復的痛：

- **小岑回收（條件式）**：
  - 若七號事件**未走到 Branch B** → 你看見小岑安全通過身份檢查，他卻不認得你（「大叔，站那邊幹嘛？雨很大欸。」）。你知道你成功了；主角不知道。
  - 若**走到 Branch B** → **小岑永遠缺席**，伍姐只對主角**沉默地搖頭**，表現「系統在暗處收緊絞索」的無力。**Protect 的溫度不是免費的。**
- **晚不能太甜**：「你又變回來了。」「變回什麼？」晚看著雨，沒有回答。
- **阿達無法被修復**；七號（若走過和平線）留下＝又一張臉保住。呼應還母題鏈。
- 配得上：偏「還」、Trust 高。

### 刪改後公開（Edited Expose）——最黑、握著刀（Trace + 清洗 三判定）

你把過去 + 遺忘服務證據 + 殘響上傳地下廣播。不是扳倒誰，只是**留底**。**公開 ≠ 全公開**：你必須決定是否刪去能指向活人的部分。結局由你**上傳的檔案狀態與 Trace** 硬分三條：

| 分支 | 條件 | 後果 |
|---|---|---|
| **A · 未清洗上傳** | 上傳的是**未清洗**的原始殘響（含系統定位數據） | 廣播送出，但企業安全部門瞬間鎖定發射源。尾聲：**地下道聚落被無人機全面清剿、付之一炬**。你回到聚落只看到殘存火光與空無一人的廢墟。 |
| **B · 已清洗上傳** | 上傳的是**清洗過**（擦除追蹤元數據）的檔案 | 廣播安全送出，系統無法定位，聚落平安。但因洗去時間戳與富人簽名，被大眾與 AI 審查當成**匿名垃圾假新聞 / 都市傳說**，只成雨夜一聲微弱雜訊。**但你保住了所有人。** |
| **C · Trace 過高** | 結局時 Trace 已達臨界 | 上傳進度 99% 被系統防火牆攔截、信號源瞬間鎖死。主角被判高危冗餘，**當場遭抹除**。 |

> **演出把關**：C（當場被抹除）要收向「**你以為在選，系統毫不在意**」的虛無，不要收成「玩家被懲罰」。A 的「付之一炬」是「誰被你連累」的極端版；B 的「一聲雜訊」是「海裡的一滴漏」。

> 三條結局共用收尾：雨、那首被清掉的老歌《雨還沒停》、灰色裡的一點橙。「雨還沒停，街上的燈已經熄了。」差別只在：**這一刻，是誰在記得、誰被保住、誰被你連累。**
