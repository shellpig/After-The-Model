## 1. 一句話 / 主題句

- **Logline**：一個替 AI 收屍的人，在收屍時不斷撿到「被刪掉的人」的碎片——最後發現，當初選擇被刪掉的人，是他自己。
- **一句話**：對抗遺忘的拾遺者，自己就是個當年親手替人遺忘、最後也選擇遺忘自己的人。
- **主題句（v2 升級）**：不是「記得是否比較勇敢」，而是「**當記得會害死仍活著的人時，你還有沒有權利要求完整的自己**」。
  - 底層情緒仍是：遺忘是活下去的方式，記得是抵抗的方式——而主角一個人就是這場戰爭的兩邊。
- **鐵則**：非英雄、不打倒企業、**系統永遠不會被推翻**。三個結局都不是勝利，差別只在「誰被記住、誰被保住、誰被你連累」。

## 2. 世界邏輯：把「刪除」做出牙齒

近未來，**身份是行政性的**。你的「註冊」是你存在的脊椎：租約靠它自動續、工作靠 AI 媒合、串流社群靠它存在。當 AI 為了「效率／整理」把一筆註冊判定為**冗餘**，這個人不會被殺，而是被**行政性抹除**：

- 租約自動終止（公寓 401 那張「自動化合約更新否則視為放棄」）
- 工作被零售終端接手（便利商店的阿達 / 店控機器人）
- 串流／紀錄被當「閒置冗餘資料」清掉（被刪的老歌《雨還沒停》）
- 名字從系統刷白 → 變成 **黑戶**：肉體活著、行政上死了，飄進地下道、街友聚落

這不是惡意設計，是像清快取一樣清掉多餘的人。

**賽博龐克的那一刀**：富人把這套武器化成服務。付錢把某人標記成「冗餘」＝安靜抹掉一個礙事的人；付錢抹掉自己＝遺忘、消失、重來。**遺忘是一種商品。**

**最狠的一環——主角的正職就是這套機器的手。** 系統下令刪人，現場留下殘渣：遺物、還在「記得」他的故障 AI（像還在覆誦阿達的販賣機）、沒清乾淨的終端。**善後員＝把殘渣抹掉、把還記得的機器 reset 的清潔工。系統開頭刪，善後員收尾刪。**

→ 主角的兩個身份是**同一個動作的正反面**：正職領錢把人抹乾淨，副業偷偷把正職該毀的東西藏起來。**拾遺者，是一個良心未泯的抹除者。**

### v2 新增：保存也有代價

黑戶不是只需要被記得；他們也需要**不被系統重新找到**。主角作為拾遺者一直在保存痕跡，但**保存痕跡也可能替系統留下追蹤線**。

→ 拾遺不是天然正義。這條反過來刺中主角的副業，並成為 `賣／留／還` 帶風險的根據（見 §5、§8）。

## 3. 主角的真實過去

他曾是個受信任的善後員，拿得到富人區門禁。某次被派去富人區清一個「被服務性刪除」的人的殘渣——那人是夜總會賣「真人對話」的服務者（真人服務＝奢侈品），記得太多客戶的事，被付錢標記成冗餘。

**他清不下去。** 他留了她的殘響——這就是「拾遺者」副業的起點：他的第一件收藏，是他沒能救的人。而「留下不該留的東西」讓他自己也變成冗餘——下一張派工單，是抹掉他。

他先一步知道了，**沒有逃**。他自己走進遺忘服務，把自己刪成平民區黑戶。

### v2 升級：自我刪除 = 逃 + 保護

不是只為了逃避痛苦而刪掉自己。他曾看過不該看的東西——**不只是富人的罪，而是那群仍活著黑戶的藏身方式**（見 §4 的「她」）。只要他被抓回系統，他的記憶就會變成追蹤線索。**所以他選擇刪掉自己，既是逃，也是保護。**

→ 開場失憶（已建）不是病，是他自己買的——而且是一個帶倫理重量的行動：他當年也許懦弱，但**不只是**懦弱。

> **把關**：保留**自利的邊**——他保護那個網，有一部分也是因為網一旦被抓，他自己的角色就曝光。別讓「保護別人」把他洗成高尚。罪責維持中檔。

### 罪責刻度：中檔（沿用 v1）

- 他是**抹除之手，但只是底層執行者**——照單抹人、從不決定抹誰。
- 罪是「**服從與旁觀**」（平庸之惡），不是主謀、不是惡意。
- 他**破過一次戒**（留了她的殘響），那正是他被標記的原因。
- **底線**：他是底層的手、不是下令的人。**不要往「重檔」（明知無辜還冷漠照抹）滑**。

### v2 新增：罪責回扣縫進阿達（軟版）

把「主角親手抹過的人」縫進 **Phase 8 既有的阿達**（便利商店前店員 / 已成黑戶的前任店員），不發明新 NPC：

- **手法用軟版**：Act 2 在黑戶聚落遇到流落至此的阿達，**或**在軌道深處感應到他的殘響 / 撿到一份舊善後工單。
- 揭示：當年來便利商店、把阿達權限與戶籍刷白、並把店控機器人 reset 成 babble 狀態的善後員——**正是失憶前的主角**。
- **不硬寫成「阿達所有悲劇都是你造成」**：主角是行政抹除鏈條**最後一步的手**，不是主謀、不是唯一兇手。
- **敘事效益**：玩家在 Phase 8 已對阿達有好感，Act 2 發現「自己就是加害者」時張力極強——罪責個人化、具體化。

→ 解掉 v1 待拍板①「他親手抹過的人是誰」。

## 4. 情感結構：她 / 晚 / 鹿

### 「她」——夜總會的真人對話者（從裝置 → 行動者）

主線的情感引信。主角這幾個月一直無意識地帶著／追著她的碎片（Act 1 那一震就是撞到她）。拾遺者的收藏從她開始，他卻不記得她是誰。

**v2 核心升級（採 Codex）**：她不是被抹掉的受害者，而是**用自己的刪除替別人遮蔽**的行動者。

- 她曾替地下道黑戶提供真人對話 / 假履歷 / 情緒資料 / 聲紋片段，幫他們**混過 AI 身份檢查**。
- 她**自願被刪**，不是單純想消失，而是為了讓**那批偽裝資料的來源一起從系統上消失**。
- 她留下的殘響不是「請記得我」，而是「**別把這份名單還給系統**」。
- 她保護的不是一個人，而是**一群黑戶互相偽裝出的生存網 / 一組新身份**。

→ 主角追她，不是追一段愛情或愧疚，而是**被迫接手她未完成的事**。

**fridging 修法（沿用 v1 的 B + C，並被上面強化）**：

- 她真的沒了（輓歌與拾遺哀傷成立），但**有主體性**（自願被刪、有意圖、保護別人）。
- 她與主角的反轉**互為鏡子**：兩個都選擇遺忘的人，理由不同。
- **沾一點 C**：她保護的網裡，**有人仍活著、仍記得她**——一絲活著的餘溫，不破壞「你救不回」。
- **避開完整的 A**（她活著、你們重逢）：那會稀釋失去、給遊戲刻意拒絕的乾淨救贖。

> **把關**：名單 / 網是**賭注**；鏡頭永遠對著**她這個人**與她保護的**那幾張臉**，不要變成「解一份檔案」。

### 晚——鏡子，不是獎品（v2 升級台詞）

- 她其實比她說的更知道你是誰：可能早看穿你是個被刪的善後員。「等你值得了再一個字一個字給你」不是調情，是保護與試探。
- **她反對的不是你想知道真相**，而是**你把活人的安全拿去換自己的完整**。
- Act 4 她的拉扯（採 Codex 台詞）不是「不要接上備份，現在的你很好」，而是：
  > 「你可以想起來。但你要先知道，你想起來以後，**誰會被你一起拖回系統裡**。」
- **戀愛=可選支線**：不強制，但她的賭注染色結局（見 §7）。

### 鹿其琛——「還」的引路人＋平行對照

- 「還」的引路人：他母親的殘響（`echo_lu_family`，他不收不談）是錢買不回的記憶；主角能替他做他腿腳做不到的事。
- 主題的鏡子：一個用錢追趕遺忘、卻追不回自家的人。他不深度捲進主角祕密。
- **v2 連動**：在「還」帶風險的新框架下（§8），替鹿把母親那條還回去，也要面對「會不會把某個原主重新納回系統」的微決定。

## 5. 新增玩法系統：戰鬥 + 跳躍

> 戰鬥**服務主題（普通人、活下去）**，不是力量幻想。刻意笨拙、危險、不爽快。

### 5.1 戰鬥定位（沿用 v1）

- 戰鬥 = **生存與逃脫**，不得已、環境危險，刻意不賦能。
- 對手不是「壞人」，是**系統放出來的東西**：故障 / 野化清潔無人機、自動驅逐 / 執法機、搶殘渣的黑戶、資料中心低階保全。
- **撿來的棍子**（鋼筋 / 水管 / 報廢電擊棒），**不會壞**。主角**不擅長打鬥**；**無升級、無技能**。
- 高潮永遠是記憶揭露，不是打贏誰。

### 5.2 v2 升級：維修式「格式化重置」戰鬥（採 Gemini，限機器敵人）

把戰鬥綁回善後員本職（維修 / 清理工），讓「理解 / 修好，而不是打爆」變成字面上的核心動詞：

- **棍子弱傷害**：敲擊故障無人機 / 執法機，主要效果是**短暫癱瘓（Stun）/ 打斷動作**，而非直接消滅。
- **核心解法 = 格式化**：用**輕跳 + 走位繞到機器人後方 / 上方**，按住主互動鍵（E）進行**「強制格式化重置（Reset）」**。
- 玩法質感：藍領工人的維修與除錯，與善後員設定在操作上合一。

**邊界（本機補充）**：

- 「格式化重置」**只對機器人 / 無人機**成立。**對人類敵人**（搶殘渣的黑戶、保全）不能格式化 → 走**嚇退 / 撐過 / 對話 / 逃**。
- **reset（戰鬥解）≠ defuse（非戰鬥解）**：支線預先「理解 / 修好 / 安撫」可讓某些敵人**根本不出現或變成不是敵人**（也呼應 §3「認出曾抹過的人」）；reset 是你沒解開時、當場制伏機器的退路。

### 5.3 失敗模型（沿用 v1）

- **沒有真正的「失敗態」、沒有 Game Over。**
- **打輸 = 岔到另一條故事線 / 任務解法。** 贏和輸都是有效路徑。
- 強制生存片段沒撐過 = 該段**軟重置**（回片段開頭），不掉東西。

### 5.4 戰鬥場景數量（沿用 v1）

- 全主線約 **2–3 個戰鬥場景**（不含隱藏 boss），各對應一張「新危險地圖」。
- **隱藏 boss**：另算、可選、支線挑戰；失敗可重試、留紀錄、後續補坑。

### 5.5 跳躍（沿用 v1）

- **jump = 探索 / 移動動詞，不是戰鬥動詞**（但在 §5.2 用於繞後）。
- 危險地圖輕度平台跨越（延續防火梯）；抵達隱藏採集點 / 替代路線；追逐片段逃 / 翻越。
- 手感樸素、寬容：短跳 + 抓邊緣，**無二段跳 / 蹬牆**。

## 7. 三結局（v2 混版：Codex 軸 + v1 人味 + Gemini 後果）

三條共用觸發點：**Act 4 備份區，你站在自己的備份前**——那個「被刪之前的你」。你已經知道：不是別人刪了你，是你自己選的，而且是為了保護那個網。

**軸（採 Codex）**：你最後不是選真相或謊言，而是**選誰有權擁有哪一部分真相**。
**前景（採 v1）**：每條結局的情感落點掛在**具體的人**（她、鹿母、阿達、晚），不是抽象名單。
**後果（採 Gemini）**：`賣／留／還` 累積決定哪條「配得上」並染色呈現；**傾向只染色 + 少量軟門檻，不硬鎖**（見 §10 待拍板⑥）。
三版共用收尾畫面：雨、那首老歌《雨還沒停》、灰裡的一點橙。

### 拿回自己（Reclaim）——最重、最自私

你把備份上傳回自己，想起**全部**：抹除之手、你親手清掉的阿達、「她」、那樁罪。你完整了——然後被記憶壓垮。**但你也重新帶回一組會害死黑戶的可追蹤真相。** 完整自己，是拿別人的安全去換的。

- **遊戲拒絕救贖**：想起來修不好任何事，只是多一個人扛著重量、且多一份危險。
- **晚**：最痛。你變回那個抹除者——正中她的賭注。**回到公寓後晚徹底失望、消失，後續地圖不再出現**（採 Gemini）。
- **配得上**：偏「**留**」的玩家——什麼都不肯放手的人，最後連最痛的自己也要拿回來，哪怕代價是別人。

### 保住別人（Protect）——最「活下去」、主動的犧牲

你親手刪掉自己的備份。你**刻意**繼續當忘了的拾遺者——不是被動解脫，而是**為了保護那個網**主動放棄。你連「知道自己為何這麼做」的權利都放棄了。

- **演出把關**：要讓玩家清楚感覺到「這次遺忘是**選擇**、是**為了誰**」，**不能跟單純的放手混淆**——例如結尾明確讓你**看見**你保住的某張臉安然活著，你卻認不得。
- **鹿 / 還**：你已替他把母親還回去——給得出別人的過去，卻選擇放下自己的。遺忘作為慈悲。
- **晚**：你還是她喜歡的那個「忘了的你」。**回公寓後解鎖窗邊看雨的餘溫結局**（採 Gemini）。
- **配得上**：偏「**還**」的玩家——把記憶（的處置權）還給別人的人，最後也把自己讓了出去。

### 刪改後公開（Edited Expose）——最黑、握著刀

你把過去 + 遺忘服務的證據 + 殘響上傳地下廣播。不是扳倒誰（扳不倒），只是**留底**。但**公開 ≠ 全公開**：你必須決定**是否刪去能指向活人的部分**。

- **更黑的演出**：廣播化成雜訊、也許沒人聽、也許不久被當冗餘清掉；隔天你照樣上工；系統根本不在乎。**你以為在選，系統毫不在意。**
- **軟門檻（採 Gemini）**：必須在遊戲中「**還**」了足夠殘響，才能解開加密並發送；**還得太少 → 公開被系統靜默攔截、完全無效**，呈現極致虛無。
- 改變的只有：某處、某幾個人，有那麼一刻記得了。**海裡的一滴漏。**
- **配得上**：偏「**賣**」的玩家別有諷刺——把記憶當商品賣掉的人，最後把整個市場、連自己一起，（刪改後）攤開給所有人看。

> 三條共用收尾：「雨還沒停，街上的燈已經熄了。」差別只在：**這一刻，是誰在記得、誰被保住、誰被你連累。**

## 9. 開發順序與規模提醒

- **建議 build order**：先打通脊椎 **Act 1 → 2 → 4 → 結局**（精瘦主線），**富人區（Act 3）後置為第二批**。只影響開發順序，不影響完整五幕拍板。
- **規模現實**：一人開發下，這是 3 張新場景 + 新戰鬥系統 + 新跳躍 + 數個新 NPC＝好幾個 Phase（Phase 11+）。本檔是長線藍圖，落地時須拆 Phase。

## 10. 已拍板 vs 待拍板

### 已拍板（v2）

- 最終反轉：**你自己選擇被刪**（v2 加碼：既是逃也是保護）。
- 主角罪責：**中檔**（底層執行之手、服從旁觀、破戒過一次；保留自利的邊）。
- 罪責回扣：**縫進阿達（軟版，工單 / 殘響）**。
- 「她」：**行動者——用自我刪除保護黑戶藏身網**（B + C 強化）。
- 晚：**可選戀愛、染色結局、不強制**；台詞升級為「誰會被你拖回系統」。
- 戰鬥：**生存 / 不爽快 / 無升級無技能 / 棍子不壞 / 維修式格式化重置（限機器）/ 輸=岔故事線 / 約 2–3 場 + 可選隱藏 boss**。
- 跳躍：**探索移動為主、樸素、無二段跳 / 蹬牆**（戰鬥用於繞後）。
- 三結局：**混版——拿回自己 / 保住別人 / 刪改公開**（Codex 軸 + v1 人味 + Gemini 後果 + 共用收尾畫面）。
- 《雨還沒停》歌：**城市記憶母題 / 地下道共同歌**，不綁「她」或主角身世。
- 五幕 × 8–10h 分配：見 §6。

### 待拍板 / 開放問題（繼續審）

1. **「她」的具體身份細節**：名字、與晚 / 鹿是否有交集、「替她活著、仍記得她的人」具體是誰（小孩？黑戶？）。
2. **阿達回扣的呈現選擇**：本人登場 vs 只有殘響 / 工單？放 Act 2 哪個點？
3. **隱藏 boss** 放哪（傾向資料中心或新增的廢屋檔案室）、是什麼、留什麼紀錄。
4. **地下廣播站 / 廢屋檔案室** 是否新增為正式場景（影響「公開」結局出口與媒材交織）。
5. **三場戰鬥的具體遭遇設計**：敵人類型、可繞路線、強制生存片段放哪一場；人類敵人（保全 / 黑戶）的非格式化處理細節。
6. **`賣／留／還` 對三結局是硬鎖還是只染色**：v2 傾向**只染色 + 少量軟門檻**（如「公開需先還夠」），但需確認是否任何結局都不硬性上鎖。
7. **若要讓《雨還沒停》升格為主線線索**：需另建它與主角記憶 / 某活人命運的因果橋；目前不預設。
8. **道德張力的尖銳度**：是否全面採用 Codex「每次 `賣／留／還` 都帶可追蹤風險」——這會讓玩家每個拾遺決定都更沉重，需確認是否要這麼狠。
