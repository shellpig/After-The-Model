## 0. 給實作者的三個前提（先讀，避免敘事破功）

1. **主角此時是失憶的善後員**，到 Phase 16 為止只撞過林霏殘響碎片①（`mem_frag_linfei_1`，純「莫名一震」），**完全不知道「林霏」這個名字**，更不知道她跟自己有關。揭露留 Phase 19 / 22。
2. 因此三人對話中 **任何一方都不准講出「林霏」三個字**。伍姐只讓玩家「知道聚落有過一個建立者、是個女的、已經沒了」——`知道有這麼一個人物`，名字與真相全部後置。
3. 七號只鋪墊「我有一個名字還掛在上面」，**不明說妹妹**（Act 2A 鉤子，payoff 在 Act 2B / 七號線）。

## 1. 角色資訊

### 小岑 —— 靠假聲紋活下來的少年黑戶
- **年齡 / 定位**：約 14–16 歲，住地下道邊緣。跑腿、偷零件、帶路維生。靠一條「別人幫他弄成聽起來像活人」的假聲紋，偶爾混過低階身份檢查。
- **個性**：嘴臭、防備、會偷主角東西。**不是純潔受害者**——是已經被城市教壞的小孩。
- **功能**：黑戶網最年輕的一張臉；Protect 結局的條件式回收對象（§8，本 Phase 不實作）。
- **守則**：別寫成可憐兮兮的小白兔；他的防備與小偷小摸是生存本能，不洗白。
- **旗標 / 信任**：`met_cen`（首見→重講路由）、`affinity_cen`（好感，已於 `開發設計方針.md` 登錄）。

### 伍姐 —— 前城市維修員，地下道的老維修人
- **定位**：管聚落電力、淨水、舊機器維修。前城市維修員，城不要她了就下來修這座沒人要的。
- **個性**：務實、冷、刀子嘴。知道很多聚落建立者的事，但**不神化她**。
- **功能（關鍵）**：**防止聚落建立者（＝林霏，但本 Phase 不具名）被供成聖女**。核心台詞「她不是好人，她只是比我們晚一點壞掉」。
- **C 版處理**：玩家不能指名打聽（主角還不知道名字）。改成玩家問「**這套東西是誰弄起來的**」這個**現象**，伍姐回答時讓玩家**知道有過這麼一個人**——但**不給名字**。
- **旗標 / 信任**：`met_wu`、`affinity_wu`（已登錄）、`knows_settlement_had_maker`（bool，新增：知道聚落有過一個建立者 / 女性 / 已不在，**不知名字、不知是林霏**；供 Phase 19 / 22 揭露時回收）。

### 七號 —— 夜總會前保安，想換回「確認某人是否還活著」的資格
- **定位**：沒固定名字，大家叫他「七號」。曾是夜總會低階保安 / 清潔工。與聚落建立者有舊交易（§4.1.1，本 Phase 不揭露）。
- **個性**：沉默、警戒、不交朋友、有壓抑的攻擊性。
- **功能**：Act 2A 鋪墊七號線的核心鉤子——「我有一個名字還掛在上面」（**不明說妹妹**）。
- **守則**：同情化 = 世界軟一格，但醜陋搬進他本人（後續他準備把小岑的位置、伍姐的舊身份賣回系統）。本 Phase 只鋪墊，不爆。
- **旗標 / 信任**：`met_seven`、`affinity_seven`（target id `seven`，已登錄）、`seven_hinted_name_topside`（bool，**16-C 鋪墊旗標**；供 Act 2A → 七號線 gate）。

## 2. 外觀描述（給 sprite / 立繪生成）

> 全員遵守 `Art Bible.md` Ch3：**flat cel-shade indie comic**、手繪粗黑墨線、Mignola 黑色塊、7–8 頭身、192px 剪影紀律（多色帶 / 腳踝斷點 / 跳色錨點在上半身）、工具塞包不外掛。
> 色盤＝**平民區地底變體**（`Art Bible.md` Ch2 平民區）：base＝deep teal / ink purple-black / gray-blue / faded olive；暖光＝faded amber（聚落暖燈泡）。
> **鐵則：飽和橙色 > 2% 是主角專屬**——三人身上**不准**用大塊飽和 burnt orange；最多極小面積 faded amber / cyan 點綴。
> 每人交付 **2 張**：①遊戲內角色圖（純側視 idle，站場景用）②對話立繪（3/4 微側半身，對話 UI 用）。

### 小岑（外觀）
- **剪影**：瘦小、兜帽罩頭的少年體型，比主角矮一截、駝一點。整體縮著、隨時準備溜。
- **服裝**：多層撿來的衣服——oversized 連帽外套（褪色 gray-blue）罩在更舊的 teal 上衣外，下身鬆垮 cargo 短褲 + 破網球鞋。
- **多色帶**：兜帽外套（gray-blue）／內層上衣（deep teal）／鞋（髒 faded olive）三段色相差明顯。
- **腳踝斷點**：鬆垮褲腳堆在破球鞋口，鞋帶亂綁。
- **跳色錨點（上半身）**：胸口一枚撿來的、會微微發 **cold cyan** 光的小零件（偷來的，極小面積）；**不可用橙**。
- **臉（~10 墨點）**：嘴角下撇、眼神斜挑防備，一道短瀏海蓋住一隻眼，臉頰一塊淡 shadow。
- **姿態**：idle＝靠帳篷邊、雙手插袋、重心壓一腳；立繪＝側身斜睨、一手護著口袋。

### 伍姐（外觀）
- **剪影**：中年、結實、肩寬，蹲 / 半蹲的工作姿態（不要英雄站姿）。一眼讀得出「老維修人」。
- **服裝**：褪色 olive / teal 連身工裝（coverall），上半袖子捲到前臂，油污補丁；腰間繫一件當圍裙用的舊布；護目鏡推在額頭（比主角的更舊更花）。
- **多色帶**：工裝上身（faded olive）／捲起的內襯（gray-blue）／厚底工裝靴（ink purple-black）。
- **腳踝斷點**：褲腳塞進工裝靴 cuff。
- **道具紀律**：工具**塞進腰包 / 大口袋**，外觀只露一兩個小細節（袖口別著的舊探針），**不外掛工具腰帶**。
- **跳色錨點**：身旁工作燈打出的 **faded amber** 暖光（環境光，非身上塗色），呼應聚落「暖人味」。
- **臉（~10 墨點）**：抿嘴、眼角細紋、短髮往後束 / 包頭巾，下巴線條硬。
- **姿態**：idle＝蹲在拆了一半的舊機器前、頭微低；立繪＝半起身、一手拿探針、抬眼斜看你。

### 七號（外觀）
- **剪影**：較高、肩背厚實、抱胸靠牆——大塊陰影吞掉半身（留黑大師 Mignola 處理）。沉默壓迫感。
- **服裝**：褪色舊保安制服改的高領夾克（deep teal-black），**胸口 / 臂章被拆掉後留下較深的色塊**（直接畫成實心黑塊，看得出「這裡曾經有徽章」）；袖子上有褪色的舊制服磨痕。
- **多色帶**：高領夾克（deep teal-black）／內襯（gray-blue）／軍靴（ink purple-black）——整體偏冷、偏暗，**不給暖色**（他是冷的）。
- **腳踝斷點**：軍靴高 cuff 翻口。
- **臉（~10 墨點）**：硬下顎、stubble、眉壓低、一道舊疤或一隻眼藏進陰影；表情無溫度。
- **姿態**：idle＝靠更深隧道口的牆、抱胸、目光沉進黑暗；立繪＝半身在暗、只一側臉受冷光側照。

## 3. Phase 16 大概對話內容（定稿草案 + 旗標）

> 結構照 `wan.gd` schema：入口恆為 `start`，由 `met_*` 旗標路由首見 / 重講；暖向選項 `add_int` 好感；terminal＝無 choices 且無 goto。
> dialogue_id：`cen` / `wu` / `seven`，落地時註冊進 `data/dialogue/dialogue_db.gd`。

### 3.1 小岑（`cen`）
**首見**
- 小岑（斜靠帳篷、上下打量你）：「新來的？地面上掉下來的吧——看你那身還算乾淨就知道。……站遠點，這是我的地盤。」
- 選項：
  - 「我不是來搶地盤的。」→ 自我介紹節點
  - 「你一個人住這？」→「關你屁事。……有人罩著，行了吧。」→ 自我介紹節點
  - 「（你感覺口袋被碰了一下）手放規矩點。」→ **被抓包分支**：「（手一縮，臉不紅）切，反應挺快。你那點破爛我還看不上。手快一點才不會餓死——你懂個屁。」→ 冷收尾（set `met_cen`）
- 自我介紹節點：「叫我小岑。別到處亂傳。……我這條嗓子，是有人幫我弄成『聽起來像活人』的，檢查機器才放我過。所以別給我惹事，我輸不起。」
  - effect：set `met_cen`、`affinity_cen += 1`
  - ⚠️ 注意：「有人幫我弄」**不具名**（那人＝林霏，但小岑不見得知道全名，且本 Phase 不揭露）。
- 暖收尾：「行了，沒事別來煩我。……真撿到吃的，分我一口，我不介意。」

**重講**：「又是你。……沒偷你東西，真的。有事說事，別老盯著我看。」
- 「來看看你。」（`affinity_cen += 1`）／「（離開）」

### 3.2 伍姐（`wu`）—— C 版（玩家問現象，不問名字）
**首見**
- 伍姐（蹲在拆一半的舊機器前，沒抬頭）：「別站光裡，擋著我看線路。……新面孔。能走到這底下，命還算硬。」
- 選項：
  - 「這些機器都是妳修的？」→ **維修人節點**
  - 「這套淨水、發電，這些能讓人混過檢查的東西——是誰弄起來的？」→ **建立者節點（C 版核心）**
  - 「（離開）」→ 收尾
- 維修人節點：「電力、淨水、誰家暖燈不亮——都歸我。以前我修地面那座城，後來城不要我了，我就下來修這座沒人要的。機器不會問你有沒有身份，比人強。」
  - effect：set `met_wu`、`affinity_wu += 1`
- **建立者節點（C 版核心，不具名）**：「（手停了半秒）……有過一個人。腦子活，手也黑。這套東西一半是她搭起來的。別把她想得太乾淨——她不是好人，只是比我們晚一點壞掉。名字？她自己把自己關掉了。知道了，對你沒好處。」
  - effect：set `met_wu`、set **`knows_settlement_had_maker`**、`affinity_wu += 1`
  - ✅ 玩家得到的：聚落有過一個**女性建立者**、能力強、道德灰、**已經不在**——「知道有這麼一個人物」。**沒有名字、沒有「林霏」、沒有與主角的連結。**
- 收尾：「想知道更多？多搬兩趟水、多修兩盞燈再說。這底下，沒人靠一張嘴活著。」

**重講**：「（抬眼瞥你一下，又低回機器）來了。手別閒著，幫我扶一下這管子——還是你只會問問題？」
- 「（搭把手）」（`affinity_wu += 1`）／「（離開）」
- （可選追問，gate＝`knows_settlement_had_maker`）：「再說說那個建立這裡的人。」→「她的事，知道太多對你沒好處。我只告訴你一件：她最後不是被抓走的，是自己把自己關掉的。至於為什麼，去問還活著的人——我不替死人講話。」（**仍不具名**）

### 3.3 七號（`seven`）
**首見**
- 七號（靠更深隧道口的牆，胳膊上有舊保安制服褪色痕跡，目光掃過你）：「……你也是躲下來的。」
- 選項：
  - 「你是誰？」→「大家叫我七號。名字早被刷掉了，留個編號剛好。我不交朋友，你也別指望我幫你。」→ 鋪墊鉤
  - 「你不像會躲的人。」→ 鋪墊鉤
  - 「（保持距離）」→ 收尾
- **鋪墊鉤（核心）**：「躲？（低笑一聲，沒有溫度）你們可以一直躲。我不行。我有一個名字……還掛在上面。（別過臉）別問了，問了你也幫不上。」
  - effect：set `met_seven`、set **`seven_hinted_name_topside`**
  - ⚠️ **全程不提妹妹**。「一個名字掛在上面」是唯一鉤子。
- 收尾：「（他不再看你，目光沉進更深的隧道口那團黑裡。）」

**重講**：「還是你。……我說過，我不交朋友。（頓）但你要真往更深的地方去，小心。那底下的東西不講話，只清場。」
- 追問（gate＝`seven_hinted_name_topside`）：「你那個『掛在上面的名字』……」→「（眼神一冷）我說了，別問。……等你哪天也丟了個非找回不可的人，你就懂了。現在，滾。」
- 「（離開）」
