# After-The-Model — NPC：晚

> 第一個街道 NPC。純氛圍 / 拾遺線方向，非派工任務發案人。本檔為 Phase 5 NPC + 對話系統的內容定稿；系統契約與子階段拆解見 `開發設計方針.md > Phase 5`、`遊戲規格書.md > Phase 5`、`測試指南.md > Phase 5` 與 `PROJECT_BRIEF.md` Phase 表。
>
> 對話樹文字為定稿草案，實作時可微調標點 / 斷行以配合 MessageBox 顯示，但語氣與分支結構以本檔為準。

## 一句話定位

> **「街角那個專看快要不存在的東西、也順便看你的女人。」**

26 歲，漂亮且自知，有個性。拾遺者的同類、消息靈通的情報來源，用俏皮與挑釁把人推開又勾住。是主角拾遺本能的一面鏡子——比主角更外放、更帶刺。

- **媒材定位**：拾遺線（對抗遺忘）的人物側，不是 AI 善後員的派工側。
- **功能定位**：拾遺線**情報來源**——好感度夠高時透露「哪裡有舊東西冒出來」的 lead。
- **長線定位**：**戀愛線**角色（5-A 不實作，僅預留好感度與旗標鉤子）。

## 視覺 / 站位

| 元素 | 說明 |
|---|---|
| 站位 | 街道中段**暗巷口**，倚靠雨棚下，面向那家拉下鐵門的死店 |
| 美術 | 角色立繪（對話 UI 用）+ 遊戲內角色圖（場景站立），**由使用者後續提供**；5-A 先用 placeholder 槽 |
| 氛圍 | 漂亮、帶刺、慵懶；雨夜、霓虹側光 |

場景錨點（對應目前街道地圖 `apartment_entrance`）：

- **DEAD SHO N 死招牌**（中段鐵門店）：她「專看快要不存在的東西」的現成標的，自帶黑色幽默。
- **暗巷**：她的站位，也是拾遺 lead 的方向。
- **左側暖光樓梯口**：主角從公寓出來的方向，開場可指。
- **最右閃爍販賣機**：勾主角 AI 善後員職業的梗（重講版用）。

## 語氣 profile

- **表層**：俏皮、愛撩、挑釁。用玩笑和調情把人推開又勾住，主動權永遠在她手上。
- **漂亮且自知**：把外貌當武器，也當盾。
- **底層**：消息靈通的拾遺同類；真心藏在玩笑下面，要夠熟才露。
- **講話方式**：短句、用畫面說話（「雨會把你沖進排水溝」）、愛丟一句讓你接不下去的話。
- **對主角**：一見面先調侃 + 撩一下，看他接不接得住；情報得「值得」才給。

## 好感度與旗標（schema 預留）

故事旗標 store（`GameState`，Phase 5 新增，variant：可存 bool / int）：

| key | 型別 | 語意 |
|---|---|---|
| `met_wan` | bool | 是否對話過（重講走短版） |
| `knows_wan_name` | bool | 是否得知她叫「晚」 |
| `affinity_wan` | int | 好感度；對話 condition / effect 讀寫；情報、戀愛線門檻共用同一值 |

- 情報 `intel` 節點以 `affinity_wan >= 2` 開鎖；不足走 `intel_locked` 婉拒。
- 戀愛線（未來）以更高 `affinity_wan` 門檻 + 額外里程碑旗標推進，不改 schema。
- effect `add_gleaner_lead <lead_id>`：拾遺 lead 鉤子；5-A 先做 log / noop（拾遺任務系統未建），僅證明資料路徑通。

## 第一段對話樹（定稿草案）

> 實作對應（見 `開發設計方針.md > Phase 5`）：對話資料入口恆為節點 `start`，`start` 為**條件路由節點**（`met_wan==true` → `retalk`，否則 → `first_meet`）。下方 `[start]` 區塊即資料節點 `first_meet`（首見）；`[start_again]` 即資料節點 `retalk`（重講）。情報分支 `[intel]` / `[intel_locked]` 由路由節點 `intel_gate` 依好感度分流。

```
[start = first_meet]
        （她斜倚在暗巷口，雨棚滴著水，看你從那盞街燈底下走出來，挑眉。）
        「喲，新面孔。從那盞燈底下、那棟漏水的破樓鑽出來的？
         我還以為那裡只剩生鏽的管線——
         沒想到還養著你這種、看得順眼的。」
   ├─①「妳在看什麼？」          → watch
   ├─②「妳是誰？」              → who
   └─③（被她看得不自在，別開眼）→ flee

[watch] （她朝那家拉下鐵門的店揚了揚下巴。）
        「那塊招牌。以前整夜亮著，現在燈死得只剩幾個字——
         『DEAD SHO』。（笑）一家斷氣的店，
         招牌偏偏拼得出『死』。這城市的幽默感，黑得很。
         我啊——專看這種快要不存在的東西。
         （斜你一眼）偶爾，也看看快要心動的東西。」
   ├─①「我也撿這種東西。」      → kin
   └─②「想跟妳打聽點消息。」    → intel_gate

[who]   「名字？這年頭名字比指紋還不值錢。
         ……晚。記這個字就好，剩下的，
         等你哪天值得了，我再一個字一個字給你。」
         〔effect: set_flag knows_wan_name〕   → watch

[kin]   （她終於正眼看你，嘴角一勾。）
        「喔——同類。那你該懂，
         撿回來的不是垃圾，是還沒被刪乾淨的人。
         （壓低聲）你這種人，我可不常遇到。」
         〔effect: affinity_wan += 1; set_flag met_wan〕   → end_warm

[intel_gate] 〔goto 條件路由〕affinity_wan >= 2 → intel；否則 → intel_locked

[intel] 〔經 intel_gate 進入〕
        「想聽好料？……算了，看在你這張臉的份上。
         巷子再往裡，那排後門堆雜物的舊樓，
         三樓搬空了，老住戶走得急，東西沒帶乾淨。
         晚了，就被收破爛的 AI 鏟平嘍。」
         〔effect: add_gleaner_lead alley_backrooms_3f〕   → end_warm

[intel_locked] 〔經 intel_gate 進入；affinity_wan < 2〕
        「消息？（笑）我又不是 AI 客服，
         憑你一句話就掏心掏肺。
         多來幾趟，讓我覺得你值得——再說。」
         〔effect: affinity_wan += 1; set_flag met_wan〕   → end_cold

[end_warm] 「下次撿到有意思的，記得拿來給我看。
            ……我是說東西。也不一定只是東西。」
[end_cold] （她又轉回去盯那塊死掉的招牌，留你一個側臉。）
[flee]     （她在你背後輕笑：「跑什麼，我又不咬人——除非你想。」）
```

**重講短版**（資料節點 `retalk`；由入口 `start` 在 `met_wan==true` 時路由進入）：

```
[start_again = retalk]
              「又是你。（瞥一眼右邊還在抽風的販賣機）
               那台破機器又卡了，等下八成是你的活。
               ……不急？那就先陪我站會兒。」
   ├─①「來看看妳。」→（effect: affinity_wan += 1）→ end_warm
   ├─②「有新消息嗎？」→ intel_gate
   └─③（離開）→ flee
```

## 戀愛線預留鉤子（非 5-A）

- 同一個 `affinity_wan` 數值往上接戀愛里程碑門檻。
- 結尾「也不一定只是東西」為戀愛線第一根引線。
- 未來里程碑用額外旗標（如 `wan_romance_stage`）推進，schema 不需改。
