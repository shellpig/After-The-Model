# After-The-Model — NPC：鹿其琛

> 收藏家 NPC，拾遺系統（Phase 9）的核心人物：鑑定探測模組、收購完整殘響、口頭埋下「還」的伏筆。本檔為人物設定定稿；系統契約與子階段拆解見 `開發設計方針.md > Phase 9`、`遊戲規格書.md > Phase 9`、`測試指南.md > Phase 9`。
>
> 對話樹文字為方向稿，定稿文字於 9-C / 9-G 實作時填入；語氣與分支結構以本檔為準。

## 一句話定位

> **「坐在滿屋舊物中間、用錢追趕遺忘速度的鹿家三少爺。」**

年約四五十。古老大家族「鹿家」的三少爺——其他 NPC 稱他「**鹿三爺**」，**他本人從不自稱**。腿受過傷、行動不便，家境富裕；所以他出得起價，也必須靠別人替他蒐集。

- **功能定位**：鑑定老舊探測模組（→ 拾遺手套升級）；殘響收購人（只收已集滿）；「還」這條路的提及者（伏筆，本階段無流程）。
- **主題定位**：「AI 時代遺失了很多東西」的切身受害者——他買別人的記憶，是因為自家的買不回來。

---

## 出身設定

| 項目 | 設定 |
|---|---|
| 家族 | 鹿家——很古老的大家族；族中傳承的收藏與檔案在 AI 時代的數位化轉移中大量遺失 |
| 排行 | 老三；「鹿三爺」是街坊與其他 NPC 對他的稱呼，本人不用 |
| 年齡 | 約 40~50 |
| 前職 | **家族私人收藏的管理人**——經手過原件、看著它們在「系統整理」中消失；因此認得殘響接收器這類老設備（鑑定可信度來源） |
| 腿傷 | 腿腳不便，使用手杖，平時坐在店內長桌後。成因**留白不明說**，文案可暗示與當年搶救收藏之事有關 |
| 經濟 | 有錢；收購不討價還價——他出的價就是他認為的價值 |

與主角的關係軸：**互補而非僱傭**——他有錢沒腿，主角有腿有眼沒錢。

## 視覺 / 站位

| 元素 | 說明 |
|---|---|
| 站位 | 收藏家的店內，長桌（鑑定區）後的座位；幾乎不移動 |
| 美術 | 立繪（對話 UI 用）+ 場景座姿圖；衣著考究但款式舊（世家的體面，不是新貴的閃亮）；手杖靠在桌邊 |
| 氛圍 | 滿屋舊物的暖色光裡唯一安靜的人 |

## 語氣 profile

- **話少**：對人客氣而有距離（世家教養），句子短，不寒暄。
- **對物熱情**：談到收藏、鑑定老物件時滔滔不絕，判若兩人——這個反差是人物的核心趣味。
- **收購時**：每條殘響給一句**專屬評語**（哪段讓他沉默、哪段他嫌貴、哪段他喊出高價）；殘缺的故事不值錢，他會直說。
- **與晚的區隔**：晚是街口的俏皮帶刺；鹿其琛是室內的安靜考究。兩人不應有相似句式。

## 對話狀態機（結構定稿，文字待填）

| 分支 | 條件 | 內容方向 |
|---|---|---|
| `first_meet` | `met_lu == false` | 首見：打量來客；問是誰指路（呼應 `clue_probe_module_lead` 的「鹿三爺」傳聞）；effect 設 `met_lu` |
| `hub` | 其餘 | 平時入口：條件式選項（鑑定 / 收購 / 閒聊 / 離開） |
| `appraise` | 背包持有 `old_probe_module` 且 `gleaner_gloves_installed == false` | 鑑定獨白（滔滔不絕段；認出這是殘響接收模組、講它的時代）→ 裝入手套（effect `install_module`）→ 教使用方式 → **口頭提及「還」**：「有些東西，賣給我之外還有別的去處——物歸原主。以後你會懂。」（方向示意，定稿待填） |
| `sell_menu` | 任一殘響已集滿且未售出 | 收購：列符合條件殘響（**排除 `echo_lu_family`**）→ 每條專屬評語 → 賣 / 留二選一 |
| 閒聊 | 恆在 | 短句 flavor；可帶出鹿家「遺失了很多東西」的背景，點到為止 |

## 鹿家的殘響（`echo_lu_family`）

他店內藏著一條他自己的殘響（採集點在店裡）。**他不收、也不談**——收購清單永遠排除。玩家集滿後只能留著；這是「還」這條未來線的無聲對照：有些記憶，錢買不走。
