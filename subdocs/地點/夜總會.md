## 場景定位

主角第一次踏進**富人區**。一座佔據塔樓 1~3 樓的奢華夜總會，把「真人對話」當奢侈品在賣、把「刪除」當富人買得起的服務。**這裡是林霏與七號交易的舊場**：七號當年是這裡的低階保安 / 清潔工，林霏在裡頭的對話包廂賣「真人對話」。主角這幾個月無意識帶著的第一件收藏——林霏的殘響——的源頭就在這個房間。

**視覺母題**：富區的「為所欲為」。擦得發亮的硬黑大理石 + 冷感金黃（champagne / brushed brass）+ 銳利 cyber-purple（AI 在看、AI 把關）。**主角的橙色手套 / 肩 patch 走進這片黑金裡是全畫面唯一的有體溫暖色——視覺直接說「你不屬於這裡」。** 嚴禁平民區的褪色 amber / burnt orange。

**功能**：Act 3 主場景；林霏核心殘響房（記憶鑰匙）；收束碎片「黑戶藏身方式」的場景錨點；保全多解小解謎（先不戰鬥，**實作時序 Phase 23**）。

## 保全解謎（先不戰鬥，多解小關卡）

> **Phase 歸屬更正（2026-06-27）**：本保全解謎依 `遊戲規格書.md` 子階段表歸 **Phase 23（Act 3 戰鬥② 人類保全潛行）**，**不在 Phase 21-A~D**。Phase 21 只做夜總會骨架 + 林霏核心殘響 + 主題歌；後場門 `back_door` 在 Phase 21 為**無條件轉場**，保全 gate（`passed_nightclub_security` / `found_staff_pass`）與保全 NPC / `bar_bot` 立繪皆已備料但**留待 Phase 23 接線**。以下為該解謎的設計事實來源，實作時序在 Phase 23。

> **拍板（2026-06-26）**：① 保全人類解謎放「門面廳→後場」（前門維持 anchor-04 自動閘門設定，人類保全放室內、貼合七號舊職）；② 四條解法全做；③ 大門口刷閘被拒只是劇情拍子、**無 Trace 風險**；④ 新旗標命名 `learned_topside_shortcut` 採用。
> **範圍註記**：本關是 **Phase 23** 的新增小機制（Phase 21 唯一系統擴充＝殘響分段媒體門檻；保全狀態 + 騷動觸發 + 多解 gate 屬 Phase 23）。賄賂複用 Phase 8 經濟；其餘為新互動邏輯。**不做完整戰鬥**（人類保全沿用 Phase 13-C「不可格式化 / 不可殺」精神，但此處不打、只智取）。

**第 0 層——大門口自動閘門（劇情拍子，不卡關）**
- examine `biometric_gate` → 刷閘**被拒** messagebox（不在賓客名單；富區 AI 把關主題）→ 提示走側邊員工 / 清潔通道。
- **無 Trace、無代價**，純把玩家導向 `service_door` 進門面廳。

**第 1 層——門面廳後場門（人類保全，四解全做）**
保全 NPC 守 `back_door`。任一解法成功 → set `passed_nightclub_security` → 後場門開放轉場。

| 解法 | 機制 | 前置 / 備註 |
|---|---|---|
| **賄賂** | 對話選項花 credits（複用 Phase 8 經濟 `add_credits` 負值 / credits 檢查）| credits ≥ 門檻才出現可成交分支；不足給回絕 |
| **假裝身份** | 對話謊稱清潔工 / 維修員 → 過 | gate＝`found_staff_pass`（門面廳 examine 舊員工工牌取得；工牌描述呼應七號舊職，**不點名七號**）；無佐證則被識破回絕 |
| **引開** | **前置**：先與保全對話（`talked_nightclub_bodyguard`）才可互動 `bar_bot`。觸發後保全 + bar_bot 淡出停用 → 中央情境圖鎖操作 5 秒 → 淡出後解鎖並開 10 秒倒數空窗 | **永久一次性**：引發即設 `nightclub_bar_bot_used`（持久、納存讀檔），用過後 `bar_bot` 只給中性訊息、不可再引發。`_bodyguard_off_post` 仍為 transient（不存檔）|
| **潛行** | 保全離崗 10 秒空窗期 E `back_door` 溜過 → set `passed_nightclub_security` | 與「引開」連動（兩步組合）；**倒數歸零未潛入＝失敗**：全暗 messagebox「保全已處理完畢」→ 保全 + bar_bot 歸位，且引開已永久燒掉，須改走賄賂 / 假裝身份 |

- 四解殊途同歸 set `passed_nightclub_security`（持久、納存讀檔）；後場門開放後可反覆進出，不重跑解謎。
- **保全永遠站在崗位**（不因通過而消失）；`passed_nightclub_security` 只負責後場門靜默放行（保全認得玩家）。
- 保全沿用人類分支語意：玩家**不能**打死 / 格式化保全；解法只有智取。
- **引開演出（2026-06-28）**：情境圖 fade-in → 鎖操作定格 5s → fade-out → 解鎖開 **20 秒**倒數；倒數＝紅色數字 + 上方「混亂時間」標題；混亂期播緊張 BGM `nightclub-chaos.mp3`（引發瞬間切入，保全歸位切回 `nightclub-1`，潛入成功由後場 `nightclub-2` 接手）。
