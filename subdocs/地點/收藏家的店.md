# 收藏家的店

> 拾遺系統（Phase 9）的新場景設計檔。只記錄本場景的敘事、layout、互動物與開放時機。
> 系統規格（殘響 / 收購 / 暫時通道）寫入 `遊戲規格書.md > Phase 9`；實作契約寫入 `開發設計方針.md > Phase 9`；人物見 `subdocs/人/鹿其琛.md`。內容文字（對話、陳設文案）標記為待填。

## 場景定位

街區之外、經暫時通道（街道最右端「離開街區」目的地選單）抵達的**小型室內舊物店**。塞滿前 AI 時代的痕跡：紙本、卡帶、相框、停產的機器。店主鹿其琛坐在長桌後，幾乎不動。

**視覺母題**：屋內暖色人味 vs 屋外冷霓虹雨夜的對比。這個房間是整個遊戲裡「被珍視的舊物」密度最高的地方——拾遺主題的展示間。

**功能**：鑑定老舊探測模組（→ 拾遺手套）、收購完整殘響、未來「還」線的提及點。

## 進出與存檔

| 項目 | 設定 |
|---|---|
| scene_id | `collector_shop` |
| entry point | 唯一：`from_street`（落門口，不播開場） |
| 去程 | 街道最右端 `leave_block` 互動 → 目的地選單 →「收藏家的店」 |
| 回程 | 店內門 → `apartment_entrance:from_collector_shop`（落街道最右端） |
| 存檔 | `can_save_here == true` |
| BGM | 場景自管；方向：安靜、近乎無聲，或一台舊唱機的微弱聲（素材待定） |

## Layout（左 → 右）

```text
[入口門] [陳列架 A] [陳列架 B] [長桌（鑑定區）+ 鹿其琛] [裡間門（鎖）]
 回街道    flavor      flavor      核心互動區                未來鉤子
```

純 2D 側捲；空間刻意小——一個房間就夠，密度優先。

- **入口門**：回街道轉場。
- **陳列架 A / B**：堆疊的舊物（紙本書、卡帶、相框、舊終端…），examine 給 flavor 淺說；是環境敘事火力區，也是 Art Bible 級的美術題材。
- **長桌（鑑定區）**：場景重心；鹿其琛坐在桌後，手杖靠桌邊；對話互動在此。
- **裡間門**：鎖著（「裡面是不給人看的」），未來鉤子——鹿家殘響的採集點就在這扇門附近。

## 已鎖定設計決策

| # | 項目 | 決定 |
|---|---|---|
| 1 | 場景結構 | 真・獨立室內場景（新 `.tscn`）；Phase 9 唯一新場景 |
| 2 | 通道 | 暫時通道 = 街道右端互動 → 目的地選單（對話樹實作）；未來地鐵站等加進同一選單；正式 TravelPanel 後置 |
| 3 | 收購介面 | 對話式成交（每條殘響專屬評語），不走 ShopPanel |
| 4 | 收購規則 | 只收**已集滿且未售出**；`echo_lu_family` 永不收 |
| 5 | 「還」 | 本階段僅鹿其琛口頭提及，無流程、無原主 NPC |
| 6 | 存檔 | 店內 `can_save_here = true` |
| 7 | 店內殘響 | `echo_lu_family` 採集點在本場景，集滿後只能留著 |
